- **Comparison of `str` vs `bytes` in Python:**
  - `str`: Unicode text (UTF-8 encoded), mutable, represented as sequence of characters (e.g., `"hello"`).
  - `bytes`: Immutable sequence of raw bytes (e.g., `b"hello"`), used for binary data (e.g., file reads/writes).

---
- **Key Differences (Generalized):**
  - **Encoding**: `str` = text (e.g., `"a"`, `"こんにちは"`), `bytes` = binary (e.g., `b'\x61'`).
  - **Mutability**: `str` is mutable (can append/modify), `bytes` is immutable.
  - **Use Cases**: `str` for human-readable text; `bytes` for low-level binary operations (e.g., network packets, file I/O).

---
- **Example (Input/Output for Processing):**
  Input: `"Input is text data; output is binary data."`
  Output: `"Text data (str) vs binary data (bytes): encoding/immutability contrast; e.g., UTF-8 vs raw bytes."`
