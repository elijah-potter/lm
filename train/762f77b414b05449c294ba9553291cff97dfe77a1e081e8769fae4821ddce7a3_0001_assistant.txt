React hooks are usable pre-made functions that allow you to tap into Reacts state and lifecycle features while developing your application. A good example of this would be the useState hook. One of the principal staples that React offers. Below is an example of useState being used to keep and update and running count of how many times a button is pressed.

import React, { useState } from 'react';

function Example() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>You clicked {count} times</p>
      <button onClick={() => setCount(count + 1)}>
        Click me
      </button>
    </div>
  );
}
