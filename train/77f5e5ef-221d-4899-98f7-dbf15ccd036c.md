The **One-Time Password (OTP) Policy**:
An emergency override system where a single-use password is generated via an approved channel (e.g., SMS, secure app) for critical access, locked after validation, and deleted immediately upon expiration. Enforced only during audits of high-risk procedures (e.g., data transfers, server reboots). Retention period: 7 days for logs; OTPs are discarded after 5 minutes of inactivity. Enforced via a scripted API call that logs failure attempts if misused.
