The task of **sorting a list of student exam scores** in ascending order by hand is complicated by a single digit change: if one student's score was originally **87** but was mistakenly written as **78** during transcription, the manual sorting process would incorrectly place that student’s grade in the wrong position relative to others with scores like **79, 80, 81, 82, 83**. This creates an incorrect ranking, requiring re-evaluation to fix.
