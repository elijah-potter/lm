Title: Unexpected `None` Return from Decorated Function

Environment:

*   Language: Python 3.11.5
*   Operating System: Windows 10
*   Editor: Visual Studio Code

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        return result + 1
    return wrapper

@my_decorator
def add_two(x):
    return x

print(add_two(5))
```

Observed Behavior:

The code prints `None` instead of the expected value of 6.

Expected Behavior:

The code should print 6, as the `add_two` function returns 5,
and the decorator adds 1 to the result.

Troubleshooting Steps:

1.  Verified the decorator logic for correctness.
2.  Confirmed the `add_two` function returns an integer.
3.  Inspected the call stack for unexpected interruptions.
4.  Simplified the decorator to a basic print statement.
5.  Checked for any global variable shadowing.
