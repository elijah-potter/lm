Comparing **file permissions** and **file ownership** in Unix/Linux:

- **File ownership** (`user:group`) defines who **administers** the file (e.g., `root:users`), controlling access via **permissions** (read/write/execute).
- **File permissions** (`rwxrwxrwx`) grants **access rights** to users/groups/others (e.g., `-rwxr--r--` allows owner read/write/execute, others read-only).
- Example: `chown` changes ownership; `chmod` modifies permissions.

For **similar items** (e.g., *REST API* vs *GraphQL*), consider:
- **REST** uses HTTP methods (`GET`, `POST`) and static endpoints; **GraphQL** queries a single endpoint with flexible schema requests.
- REST enforces stricter **request-response cycles**, while GraphQL allows **on-demand data** via a single query.
