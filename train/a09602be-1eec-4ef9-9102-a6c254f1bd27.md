Title: Unexpected `None` Return from `sorted()` with Custom Key

Environment:

*   Language: Python 3.11.5
*   Operating System: macOS 13.6.3
*   Editor: VS Code v1.84.2

```python
data = [
    {"name": "Alice", "score": 85},
    {"name": "Bob", "score": 50},
    {"name": "Charlie", "score": 50},
    {"name": "David", "score": 50}
]

def get_score(item):
    return item["score"]

sorted_data = sorted(data, key=get_score)
print(sorted_data)
```

Observed Behavior:

The code produces a `TypeError: '<' not supported between instances of 'None' and 'int'`.  The error originates within the `sorted()` function during the comparison of key values. This indicates that the `get_score` function is unexpectedly returning `None` for some items in the `data` list.

Expected Behavior:

The `sorted()` function should return a new list containing the items from `data` sorted in ascending order based on the `score` key. Items with the same score should maintain their original order. The error should not occur.

Failed Troubleshooting Steps:

1.  Verified that all dictionaries in `data` contain a `score` key.
2.  Inspected the `data` list for `None` values directly.
3.  Checked for type errors within the `get_score` function.
4.  Attempted to print the return value of `get_score` for each item.
5.  Simplified the `get_score` function to simply return `item["score"]`.
