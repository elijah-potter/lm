# **Basic File Backup Script**
**Purpose:** Create a compressed backup of a directory to a secure location.

---
**Prerequisites:**
- Ensure you have write permissions to the backup destination.
- Check available disk space before running the script.

---

### **Instructions:**

1. **Identify Target Directory**
   Replace `$(pwd)/source_dir` with your source folder path:
   ```bash
   SOURCE_DIR="$(pwd)/source_dir"
   ```

2. **Specify Backup Location**
   Replace `backup_path` with your desired backup directory (e.g., `~/backups` or `/mnt/backup`):
   ```bash
   BACKUP_PATH="~/backups"
   ```

3. **Create Timestamped Backup**
   Run this command to generate a compressed archive:
   ```bash
   tar -czvf "${BACKUP_PATH}/backup_$(date +%F).tar.gz" -C "$(dirname "$SOURCE_DIR")" "$(basename "$SOURCE_DIR")"
   ```

4. **Verify Integrity**
   Check the backup exists:
   ```bash
   ls -lh "${BACKUP_PATH}/backup_*.tar.gz"
   ```

---
**Optional Enhancements:**
- Use `rsync` for incremental backups:
  ```bash
  rsync -avz --progress "$SOURCE_DIR" "${BACKUP_PATH}/backup_$(date +%F).rsync"
  ```
- Add encryption for sensitive data:
  ```bash
  gpg -c "${BACKUP_PATH}/backup_*.tar.gz"
  ```

---
**Cleanup:**
Delete the original if the backup is verified:
```bash
rm -rf "$SOURCE_DIR"
```
