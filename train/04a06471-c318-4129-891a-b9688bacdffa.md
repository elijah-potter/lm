1. Start by defining the purpose of the piece: "Instructions for [specific task]"

2. Use imperative mood for commands: "Write a list of steps," "Use bullet points," "Include examples if applicable."

3. Structure with clear headings:
   ```
   **Section Headings**
   - Step 1: [Action]
     - Subpoints: [Additional details]

   - Section 2: [Another Action]
     ```

4. Example:
   ```
   **Task: Organize a Dataset for Machine Learning**

   **1. Data Collection**
   - Gather raw data from [source] (CSV, JSON, etc.).
   - Ensure compliance with [licensing/privacy regulations].

   **2. Data Cleaning**
   - Remove duplicates: `df.drop_duplicates(inplace=True)` (Python example).
   - Handle missing values: Impute with mean/median or drop rows.

   **3. Feature Engineering**
   - Normalize numerical features: Scale to [0-1] or [min-max].
   - Encode categorical variables: Use `pd.get_dummies()` or label encoding.

   **4. Validation**
   - Split data: 80% train, 20% test (stratified if needed).
   - Check for bias or outliers using visualizations (e.g., boxplots).

   **5. Save**
   - Export cleaned dataset to `.parquet` or `.feather` format for efficiency.
   - Label files: `train_*.parquet` for training, `test_*.parquet` for validation.
   ```
