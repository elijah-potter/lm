Cloud computing concept is used on information technology platform as one to many or many to one. It means the data or files stored by different people get updated to a central system and they can access or share their files if needed at any time and any where over the internet.
Data centers are the facilities where cloud storage system is done. For a small level, a cloud storage system needs only one data server connected to internet, but they depend on hundreds of data servers as the information for their clients’ needs to be accessed round the clock irrespective of any problems like malfunctioning of computer hardware, internet connectivity, power supplies etc.
Types of cloud computing
Cloud computing providers offer services to their clients based on three fundamental models. First one is the Infrastructure as a service (IASS) which is the basic cloud service model that includes virtual machines, storage, servers, load balancers and networks. The next one is the platform as a service (PASS) which is a computing platform or solution stack which includes execution runtime, web server, development tools and database. The last is the software as a service (SAAS) where the cloud providers install and operate application software which includes Email, games, virtual desktop, CRM etc.
Cloud computing concept helps the small clients, who need not invest their capital for setting up of the networking infrastructure as it may turn out to be an inorganic investment with high deprecation on it over the years. They can pay for what they use.
