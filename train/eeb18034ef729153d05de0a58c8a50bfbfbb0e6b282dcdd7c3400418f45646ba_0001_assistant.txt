Sure no problem! Here is a program that will do that using the `input()` function to ask a question and a `for` loop to check the answer.:

# Ask a question
answer1 = input("1. Dvorak is a layout of what? ")
# Check the answer
if answer1.lower() == "keyboard":
    print("Right")
else:
    print("Wrong")
    
# Ask a second question
answer2 = input("2. Who is considered to be the father of the computer? ")
# Check the answer
if answer2.lower() == "charles babbage":
    print("Right")
else:
    print("Wrong")
    
# Ask a third question
answer3 = input("3. What does the \"S\" in \"HTTPS\" stand for? ")
# Check the answer
if answer3.lower() == "secure":
    print("Right")
else:
    print("Wrong")

Each question is used as an `input()` prompt to define a variable as the answer; in this case, they are variables `answer1`, `answer2`, and `answer3`. The `if` statements test the correct answer against the answer variable after formatting it as lowercase text so that any capitalization can be used in the input answer. If it matches, the program will print "Right" as output. If the answer doesn't match, it will print "Wrong" instead. Let me know if you need anything else!
