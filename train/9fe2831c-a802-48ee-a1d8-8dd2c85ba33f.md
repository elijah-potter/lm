Title: Unexpected `None` Return from `sorted` with `key`

Environment:

*   Language: Python 3.11.5
*   Operating System: macOS 13.6.3
*   Editor: Visual Studio Code

```python
data = ["apple", "banana", "cherry", "date"]

def length_key(item):
    return len(item)

sorted_data = sorted(data, key=length_key)

print(sorted_data)
```

Observed Behavior:

The code unexpectedly prints `None` instead of the sorted list. The program terminates immediately after this output.

Expected Behavior:

The code should print the list `['date', 'apple', 'banana', 'cherry']`, which is the original list sorted by string length.

Troubleshooting Steps:

1.  Verified Python installation with `python --version`.
2.  Confirmed the `length_key` function operates as intended.
3.  Checked for typos in the `sorted` function call.
4.  Inspected the `data` list for unexpected elements.
5.  Simplified the `length_key` function to `lambda x: x` to eliminate potential issues within the function itself.
