The Data Architecture module explores how data is identified, processed, stored and how different data flows through an organisation.
This is linked to the design and use of data in structured formats and contains descriptions of data placement, storage, flows and governance.
The module also explains the role of a data architect and the requirements needed to implement successful data architecture.
Learn what data architecture is. Learn why data architecture is important. Understand how data architecture is implemented. Understand what the role of data architect is. Understand what data architecture framework is. Learn the requirements of data architecture. Understand some of the constraints to implementing data architecture.
Who is Suitable?
No prior knowledge is required so all Data Practitioners can undertake the course. As this is a data architecture & IT module the content is especially useful for data architects but would also be a useful for a wide spectrum of data roles; including but not exclusive to data owners, data stewards, data modellers, data analysts and data lineage analysts.
- What is Data Architecture?
- What is the difference between a data architect and a data modeller?
- How do forces at work affect data architecture?
- Why might an organisation decide to change its data architecture?
- What are strategic objectives and intent with regards to systems and data architecture?
