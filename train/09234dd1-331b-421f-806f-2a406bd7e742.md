The difference between **JSON (JavaScript Object Notation)** and **YAML (YAML Ain’t Markup Language)**:

1. **Syntax**:
   - JSON uses key-value pairs enclosed in `{}` and `[]`, with values often in quotes (e.g., `"key": "value"`).
   - YAML uses indentation for structure (e.g., `key: value`) and supports multi-line strings without escaping.

2. **Data Types**:
   - JSON restricts data to strings, numbers, booleans, arrays, objects, and `null`.
   - YAML supports more types (e.g., `null`, `true`, `false`, `~` for `null`), and nested structures more flexibly.

3. **Portability**:
   - JSON is language-neutral and universally supported (e.g., APIs, configs).
   - YAML lacks broad adoption in APIs but excels in human-readable configs (e.g., Docker, Ansible).

4. **Escaping**:
   - JSON requires escaping special characters (e.g., `"key": "hello\nworld"`).
   - YAML uses `|` (literal) or `>` (folded) for multi-line strings without escaping.

5. **Use Cases**:
   - JSON: APIs, databases, configs (e.g., `config.json`).
   - YAML: DevOps tools, configs (e.g., `docker-compose.yml`).

---
Example:
```json
{"name": "Alice", "age": 30}
```
```yaml
name: Alice
age: 30
```
