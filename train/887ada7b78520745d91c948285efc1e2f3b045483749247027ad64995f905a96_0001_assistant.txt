That sounds like a fun game for kids. Here are three name ideas you could use:

- Sunk! - This name would work because things can happen that can cause a ship to be sunk, and have to start at the beginning which poses the biggest challenge to winning the game.
- Avast! - This game name could work because "avast" is a word used by pirates and will add to the theme of the game, making it more memorable due to the association.
- X Marks the Spot - Treasure maps end with an "X" indicating where the treasure is buried. Since the goal of this game is to get to the end of the map, it makes sense that the end spot is an "X."
