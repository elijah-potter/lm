Title: Unexpected `null` Value During Dictionary Iteration

Environment:
* Python: 3.11.5
* Operating System: macOS 13.6.3
* Editor: Visual Studio Code v1.83.1

```python
my_dict = {"a": 1, "b": 2, "c": 3}
for key, value in my_dict.items():
    if value == 2:
        print(f"Found value 2 at key: {key}")
    else:
        print(f"Value {value} at key {key}")
```

Observed Behavior:

The code executes without error, but the output for keys "a" and "c" is unexpected. The program prints "Value 1 at key a" and "Value 3 at key c", instead of proceeding to the next iteration as intended. The program appears to terminate prematurely after processing the first key-value pair.

Failed Troubleshooting Steps:

1. Verified Python version and syntax.
2. Checked for typos in the dictionary keys and values.
3. Confirmed the dictionary is not being modified elsewhere.
4. Examined the conditional statement for logical errors.
5. Attempted debugging with a breakpoint at the `print` statement.
