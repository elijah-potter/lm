Title: Unexpected `NullPointerException` with Java Streams

Environment:
* Java: 17.0.2
* OS: macOS 13.5.1
* Editor: IntelliJ IDEA 2023.1.5

```java
import java.util.List;
import java.util.stream.Collectors;

public class StreamExample {

    public static void main(String[] args) {
        List<String> data = List.of("apple", "banana", null, "cherry");

        List<String> processedData = data.stream()
                .filter(s -> s != null && s.length() > 2)
                .map(String::toUpperCase)
                .collect(Collectors.toList());

        System.out.println(processedData);
    }
}
```

Observed Behavior:

The program throws a `NullPointerException` at runtime. The
exception occurs within the `map` operation. The stack trace
indicates a `NullPointerException` originating from the
`String::toUpperCase` method.

Expected Behavior:

The program should execute without error. The `filter`
operation should remove the `null` element from the stream.
The remaining strings, those with lengths greater than 2,
should be converted to uppercase and collected into a list.
The resulting list should contain `[APPLE, BANANA, CHERRY]`.



Troubleshooting Steps:

1.  Verified that the `data` list contains a `null` element.
2.  Added a null check within the `map` operation:
    `.map(s -> s != null ? s.toUpperCase() : null)`
    This introduces a `null` element into the output list,
    but the `NullPointerException` persists.
3.  Confirmed that `String::toUpperCase()` does not throw
    exceptions for valid strings.
4.  Examined the stream pipeline for potential side effects.
    The pipeline is straightforward.
5.  Used a debugger to step through the stream pipeline. The
    `NullPointerException` occurs during the `map` operation,
    even when the `filter` appears to be functioning correctly.
