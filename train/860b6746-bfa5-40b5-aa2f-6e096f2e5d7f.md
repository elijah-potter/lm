**Step 1:** Open a text editor or terminal environment.

**Step 2:** Prepare a blank document or use an existing file.

**Step 3:** Use the following template as a starting point:

---
### **Instructions for [Task]**

1. **Understand the Objective**
   Clearly define what you aim to achieve (e.g., create, analyze, transform).

2. **Gather Requirements**
   List all necessary inputs, constraints, or rules (e.g., input format, size limits, error handling).

3. **Define Input/Output**
   Specify the expected input format (e.g., file path, JSON structure) and output criteria (e.g., file extension, validation rules).

4. **Step-by-Step Execution**
   Break down the process into actionable steps (e.g., parsing, processing, formatting).

   Example:
   - **Input:** Input file (`.txt`).
   - **Step 1:** Validate file exists and is readable.
   - **Step 2:** Read file line by line.
   - **Step 3:** Apply [algorithm] to each line.
   - **Step 4:** Save results to `[output_file].csv`.

5. **Error Handling**
   Include conditions for invalid inputs (e.g., missing files, unsupported formats).

6. **Testing**
   Provide sample inputs/outputs to verify correctness.

7. **Optimization**
   Suggest improvements (e.g., parallel processing, memory efficiency).

---
**Step 4:** Replace placeholders (e.g., `[Task]`, `[algorithm]`) with your actual instructions.

**Step 5:** Save the document as `instructions_[task].txt` or similar.
