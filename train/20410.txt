A percentage is a number out of 100, so we need to make our denominator 100!
If the original denominator is 19, we need to solve for how we can make the denominator 100.
To convert this fraction, we would divide 100 by 19, which gives us 5.26.
Now, we multiply 5.26 by 144, our original numerator, which is equal to 757.89
757.89 / 100 = 757.89%
Remember, a percentage is any number out of 100. If we can balance 144 / 19 with a new denominator of 100, we can find the percentage of that fraction!
