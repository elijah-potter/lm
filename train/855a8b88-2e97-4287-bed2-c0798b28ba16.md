Comparison: **Algorithm vs. Function**
- **Algorithm**: A step-by-step procedure for solving a problem (general, abstract method).
- **Function**: A named, reusable block of code performing a specific task (concrete implementation).

---
Comparison: **JSON vs. XML**
- **JSON**: Lightweight, key-value pairs, easy to parse with minimal syntax (e.g., `{ "key": "value" }`).
- **XML**: Structured, tag-based, supports metadata (e.g., `<root><item>value</item></root>`).

---
Comparison: **File Permissions (Linux)**
- **User (u)**: `rwx` (read/write/execute).
- **Group (g)**: `rwx` (same as user).
- **Others (o)**: `r-x` (read/execute only).

---
Comparison: **`grep` vs. `awk`**
- **`grep`**: Text search with pattern matching (e.g., `grep "error"`).
- **`awk`**: Pattern scanning + data processing (e.g., `awk '/error/ {print}'`).

---
Comparison: **`sort` vs. `uniq`**
- **`sort`**: Orders lines numerically/lexicographically (e.g., `sort file.txt`).
- **`uniq`**: Removes duplicate consecutive lines (e.g., `sort file.txt | uniq`).
