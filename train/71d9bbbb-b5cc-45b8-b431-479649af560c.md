The rule mandates that all files in `/data/` must be encrypted with AES-256-GCM using a key derived from `/etc/secrets/encryption_key` rotated monthly. Unencrypted files in `/data/` or access attempts via `sudo` without explicit `ENCRYPT` flag will result in a 403 Forbidden HTTP response in API v3 endpoints. Audit logs must include all operations on `/data/` with timestamps, user, and action type (read/write/delete).
