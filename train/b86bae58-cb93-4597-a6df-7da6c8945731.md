1. **Key Difference**: **Convolutional Neural Network (CNN)** vs. **Recurrent Neural Network (RNN)**:
   - **CNN**: Excels in **spatial hierarchies** (e.g., images), using **local connectivity** and **weight sharing** via filters/kernels.
   - **RNN**: Optimized for **sequential data** (e.g., time-series, text), handling **temporal dependencies** with **memory cells** (e.g., LSTM/GRU).

2. **Core Processing**:
   - **CNN**: Focuses on **feature extraction** via convolutions, pooling, and activation maps.
   - **RNN**: Uses **recurrent loops** to propagate context across time steps, storing intermediate states.

3. **Applicability**:
   - **CNN**: Best for **static data** (images, grids) where spatial relationships matter.
   - **RNN**: Best for **dynamic data** (NLP, audio) where order/sequence is critical.

4. **Example Use Cases**:
   - **CNN**: Object detection in satellite imagery, facial recognition.
   - **RNN**: Language modeling, sentiment analysis in tweets, speech synthesis.
