A **meta-keyboard shortcut** for **context-aware macro expansion** in command-line environments:

```sh
# Shortcut: `⌃⌘↑` (Ctrl+Cmd+Up Arrow) expands predefined multi-word commands
# Example:
⌃⌘↑ ls -l /path/to/files  → `ls -l /path/to/files`

# Customizable via `~/.config/macropaths.conf`:
[macro "install-dependencies"]
    sudo apt install -y \
        python3 \
        git \
        curl \
        build-essential

# Trigger: `⌃⌘↑ install-dependencies`
```

For CLI tools like `zsh`, `fish`, or `tmux`, this reduces repetitive typing by predefining complex commands.
