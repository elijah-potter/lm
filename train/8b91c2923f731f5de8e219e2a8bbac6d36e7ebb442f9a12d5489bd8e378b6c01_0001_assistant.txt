This function will accomplish that for you:

```
# Define the function
def encrypt_password(password):
    # Convert the password to a binary string 
    binary = "".join(format(ord(c), "08b") for c in password)
    
    # Append the binary password to the end of the file
    with open("passwords.txt", "a") as f:
        f.write(binary + "\n")
        
    print("Password encoded and appended!")
    
# Define a password and call the function
mypassword = input("Enter password: ")
encrypt_password(mypassword)
```

The `encrypt_password()` function will accept a text string `password` as an argument, then use an embedded `for` loop to convert the password to binary. How it works is by iterating over every character `c` in the string `password`, converting them to ASCII with `ord()`, and then formatting the ASCII as binary with `format()` using `08b` to specify binary. It adds those to an empty string with `.join()` so that the full string is the binary translation of the password. With the password converted to binary, the function uses `with open` to open "passwords.txt", clarifying append mode with `a` to prevent previous entries from being overwritten, and writes the password to a new line. At the end, outside the function, the password is accepted as input to define the `mypassword` variable, and the function is called with `mypassword` as an argument.
