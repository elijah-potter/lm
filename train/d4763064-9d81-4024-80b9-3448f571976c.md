Title: Unexpected `nil` Value in Ruby Hash Iteration

Environment:
* Ruby: 3.2.2
* OS: macOS 13.5.1
* Editor: VS Code v1.83.1

```ruby
data = {
  "a" => 1,
  "b" => 2,
  "c" => 3,
  "d" => nil
}

data.each do |key, value|
  puts "Key: #{key}, Value: #{value}"
end
```

Observed Behavior:

The code prints "Key: d, Value: " to the console.
A trailing space appears after the key "d" when the value is `nil`.

Expected Behavior:

The code should print "Key: d, Value: nil".
No trailing space should appear after the key "d".

Troubleshooting Steps:

1. Verified Ruby version and syntax correctness.
2. Examined the data structure for unexpected characters.
3. Tested with a different data structure (array).
4. Searched Ruby documentation regarding `nil` handling.
5. Attempted to explicitly check for `nil` values.
