There are some important differences in the way that HTML and XHTML deal with the content inside the scripts. In HTML, the content type is declared as
CDATA, which means that HTML entities will not be parsed. However, in XHTML, the content type is declared as
#PCDATA, which means that entities will be parsed.

Like all other HTML tags, the
<script> tag supports the global attributes in HTML5.
<script> tag also supports the event attributes in HTML5.
<script> tag is supported in all major modern browsers.
Tip:Check out the
<noscript> element which provides an alternate content for users that have either disabled scripts in their browser or have a browser that doesn't support client-side scripting.
