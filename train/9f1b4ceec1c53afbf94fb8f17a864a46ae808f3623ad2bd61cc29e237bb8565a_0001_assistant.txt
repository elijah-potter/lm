```Python
# Function that returns 3 random cards and prints 3 messages
def pick_three_cards(cards):
  three_cards = random.sample(list(cards), 3)
  print("Your past is", cards.get(three_cards[0]))
  print("Your present is", cards.get(three_cards[1]))

```

After importing the `random` module, we define the function `pick_three_cards` that accepts a dictionary of cards as an argument.
