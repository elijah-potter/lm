Python 3.6 introduced formatted string literals, or f-strings, that allow you to embed variables directly into a string inside curly braces by preceding the string with an "f" at the beginning. This is different from the str.format() method that includes placeholder curly braces and specifies the variables in a .format() method at the end of the string.

Here is an example comparing the two methods:

name = "Sam"
profession = "programmer"
language = "Python"

# str.format() method example
print(("{} is a {} who specializes in the {} language.").format(name, profession, language))

# f-string method example
print(f"{name} is a {profession} who specializes in the {language} language.")

These will both output, "Sam is a programmer who specializes in the Python language." As you can see, the f-string method is typically more concise and readable than the str.format() method.
