No problem. Here's the mostly equivalent code in Rust:

pub fn print_single_styled_line(text: &str, fg_color: &str, bg_color: &str, trailing_newlines: usize) -> () {
    println!("{}{}{}", fg_color, bg_color, text);
    for i in 0..trailing_newlines {
        println!("\n");
    }
}


#[allow(non_snake_case)]

The ANSI escape strings are changed at the beginning to work with Rust (octal vs. hex), but they are otherwise the same. However, the caveat is that Rust's println macro automatically adds a new line, so the trailing new lines you would pass in would be one less than you would want. There's no straightforward way to have no newline at all.
