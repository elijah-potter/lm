**Rules of the Code:**

1. **Input Validation**: All inputs must be validated against predefined schemas before processing.
2. **Data Integrity**: Ensure no data corruption occurs during any operation; checksums must be verified.
3. **Error Handling**: Log all exceptions with traceback details for debugging.
4. **Performance**: Optimize operations to handle peak loads (e.g., <10ms per query).
5. **Security**: Sanitize all user inputs; disable shell injection via strict parsing.
6. **Atomicity**: Database operations must be transactional; rollback on failure.
7. **Audit Logging**: Track every command execution with timestamp, user, and parameters.
8. **Rate Limiting**: Enforce 100 requests/minute per user to prevent abuse.
9. **Environment**: Use `.env` for secrets; never hardcode credentials.
10. **Idempotency**: Design commands to be safely replayed without side effects.
11. **Compliance**: Follow GDPR/CCPA for data retention and deletion policies.
12. **Output Formatting**: JSON/YAML for structured logs; CSV for tabular exports.
13. **Monitoring**: Alert admins via Slack/email on system anomalies.
14. **Testing**: Automate CI/CD pipelines with unit/integration tests.
15. **Documentation**: Maintain up-to-date README with API usage and dependencies.
