**Incremental Adaptation in Phased Evolution:**

1. **Initial State:**
   - Baseline: `S₀ = [A₀, B₀, C₀]`
   - Constraints: `L₀ = [C₁, C₂]` (e.g., latency ≤ 1s, accuracy ≥ 85%)

2. **Step 1 (T=1):**
   - **Action:** Apply heuristic: `A₁ = A₀ ∪ {X₁}`, where `X₁` = "adjust batch size to 32".
   - **Impact:** `S₁ = [A₀ ∪ {X₁}, B₀, C₀]`
   - **Metrics:**
     - Latency: `L₁ = max(L₀, ΔL₁)`, where ΔL₁ = +0.1s (if X₁ violates C₁).
     - Accuracy: `A₁ ≥ 83%` (if X₁ reduces precision).

3. **Step 2 (T=2):**
   - **Action:** Conditional rule: If `L₁ ≤ 1.1s`, add `B₂ = {Y₂}` = "prune depth 2 layers".
   - **Impact:** `S₂ = [A₀ ∪ {X₁, Y₂}, B₀, C₀]`.
   - **Metrics:**
     - Latency: `L₂ = min(L₁, ΔL₂)` (if Y₂ reduces latency).
     - Accuracy: `A₂ = A₁ + ΔA₂` (e.g., +2%).

4. **Iterative Pattern:**
   - **Generalize:** `Sₙ = Sₙ₋₁ ∪ {Zₙ}`, where `Zₙ` = `{Z₁, ..., Zₙ}` are micro-steps.
   - **Termination:** `Sₙ` satisfies `Lₙ ≤ C₁ ∧ Aₙ ≥ C₂`.
   - **Output:** `𝒮ₙ = (Aₙ, Bₙ, Cₙ) = (A₀∪Zₙ, B₀, C₀)`.
