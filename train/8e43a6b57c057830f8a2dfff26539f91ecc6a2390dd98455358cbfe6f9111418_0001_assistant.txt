This function will let you create a set and add to it:

# Create the set
new_set = set()

# Define a function to create a set
def add_to_set():
    # Request added value
    addition = input("What would you like to add to the set? ")
    new_set.add(addition)
    # Print the set
    print(new_set)

It first creates a new empty set called `new_set` using `set()`. Then it uses `def` to define a new function called `create_set()` that will add to `new_set` and request an added value for the set with an `input()` function. Then it appends the new object to the set with `.add()` and prints the new set when it is called.
