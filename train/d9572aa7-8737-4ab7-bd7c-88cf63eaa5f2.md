Title: Unexpected `NullPointerException` with Java Streams

Environment:
* Java: 17.0.2
* OS: macOS 13.4
* Editor: IntelliJ IDEA 2023.1.4

```java
import java.util.List;
import java.util.stream.Collectors;

public class StreamNullPointer {

    public static void main(String[] args) {
        List<String> names = List.of("Alice", null, "Bob", "Charlie");

        List<String> processedNames = names.stream()
            .map(String::toUpperCase)
            .filter(name -> name != null)
            .collect(Collectors.toList());

        System.out.println(processedNames);
    }
}
```

Observed Behavior:

A `NullPointerException` is thrown during the `.map()` operation. The program terminates abruptly with the error message: "java.lang.NullPointerException at StreamNullPointer.lambda$main$0(StreamNullPointer.java:7)".  The program does not print the expected list of uppercase names.

Expected Behavior:

The stream should gracefully handle the `null` element in the input list. The `filter` operation should remove the `null` value before any subsequent operations are performed. The program should then print a list containing "ALICE", "BOB", and "CHARLIE".



Troubleshooting Steps:

1.  Verified the input list contains a `null` element.
2.  Confirmed the `filter` operation is present in the stream pipeline.
3.  Inspected the `String::toUpperCase` method for errors.
4.  Reviewed Java documentation regarding stream handling of `null` values.
5.  Simplified the stream pipeline to isolate the error.
