There is a way to make it simpler! Pandas DataFrames has an inbuilt CSV reader so that you can avoid importing the `csv` module at all. Here's how you would use it:

```
import pandas as pd

# Read the CSV to a DataFrame
df = pd.read_csv("goals.csv")

# Drop the Q1 column
df = df.drop("Q1", axis = 1)

# Write the DataFrame back to a CSV
df.to_csv('goals.csv', index = False)
```

This script reads the CSV with the Pandas `.read_csv()` method, drops the Q1 column, and writes the new data back to the CSV with `.to_csv`. It simplifies your code to a single module and four lines rather than two modules and six lines, and it has the added benefit of being more readable and putting less demand on the computer to load data.
