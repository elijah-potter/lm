A **macro key** configuration could be defined with **Windows Key + Shift + D** to toggle a custom placeholder (e.g., `//TODO`) in an editor (like VS Code or Notepad++) without adding extra keystrokes.

For example:
- **Trigger:** `Win+Shift+D`
- **Action:** Insert `// TODO: [cursor position]`
- **Result:** No extra typing, but the placeholder is still visible in code reviews.

Alternative: **Snippet expansion** (e.g., in VS Code) to auto-populate boilerplate like:
```
function handleError({message, code} = {}) {
  console.error(`[${code}] ${message}`);
}
```
No shorter, but **faster to type** after initial setup.
