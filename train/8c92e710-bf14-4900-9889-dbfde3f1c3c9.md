Title: Unexpected `TypeError` with `collections.Counter`

Environment:
Python 3.11.5
macOS 13.6.3 (Ventura)
Visual Studio Code v1.85.2

```python
from collections import Counter

data = [1, 1, 2, 2, 2, 3, 3, 3, 3]
counts = Counter(data)
print(counts[4])
```

Observed Behavior:

A `TypeError` occurs. The error message is:
"TypeError: unorderable types: <class 'Counter'> and <class 'int'>"

Expected Behavior:

The code should return `0`.  If a key is not found
in the `Counter` object, it should return zero, not
raise a `TypeError`.



Troubleshooting Steps:

1. Verified Python version using `python --version`.
2. Confirmed `Counter` object is correctly instantiated.
3. Examined the `Counter` object's keys; 4 is not present.
4. Searched the official Python documentation for `Counter`.
5. Tested with a simpler `Counter` containing only integers.
