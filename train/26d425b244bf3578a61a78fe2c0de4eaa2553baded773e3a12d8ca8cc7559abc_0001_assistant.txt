It needs to include `response.content`, which will tell it to use the `response` object from the `requests.get()` call. It's better to use `.content` than `.text` when parsing for HTML tags to prevent character encoding from causing issues. Using `.text` is better when printing the content directly for readability, but `.content` uses raw bytes, which are easier for the scraper to decipher.
