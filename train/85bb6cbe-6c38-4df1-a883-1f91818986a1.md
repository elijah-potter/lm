## A Practical Guide to Telescope.nvim: Beyond Fuzzy Finding

Hey r/neovim!

I've been diving deep into Telescope.nvim lately, and I think it’s significantly improved my workflow. While many are familiar with it as a fuzzy finder, its capabilities extend far beyond that. This guide aims to cover installation, basic usage, and some more advanced tricks to really leverage Telescope's potential.

**What is Telescope?**

Telescope is a highly customizable fuzzy finder, code picker, and interactive query tool for Neovim. Built on the FZF (fuzzy finder) engine, it offers speed and flexibility while integrating seamlessly into the Neovim environment. It’s more than just a replacement for `:find` – it’s a powerful springboard to various files, buffers, history, and more.

**Installation**

The preferred method is using your plugin manager. Here are examples for popular managers:

* **vim-plug:**

```vim
Plug 'nvim-telescope/telescope.nvim'
```

Then run `:PlugInstall` in Neovim.

* **Packer:**

```lua
use {
  'nvim-telescope/telescope.nvim',
  requires = {
    'nvim-lua/plenary.nvim'
  }
}
```

Run `:PackerSync` to install.

* **Lazy.nvim:**

```lua
{
  'nvim-telescope/telescope.nvim',
  dependencies = { 'nvim-lua/plenary.nvim' }
}
```

Lazy will handle the installation upon loading the configuration.

**Important Dependency: Plenary.nvim**

Telescope requires `plenary.nvim` for several functionalities. Ensure it’s installed alongside Telescope, as shown in the examples above.  It provides Lua utilities that Telescope relies on.

**Basic Usage**

After installation, Telescope is accessible via the `:Telescope` command. This will launch the default picker, which lists files in the current directory.  Let’s explore some common pickers:

* **`:Telescope find`**:  Find files within the current directory and its subdirectories.  This is the most common starting point.
* **`:Telescope buffers`**:  List all open buffers. This is far more efficient than manually switching between them.
* **`:Telescope history`**:  Browse your command history. A lifesaver for recalling frequently used commands.
* **`:Telescope registers`**:  List all registers. Useful for retrieving previously copied or deleted text.
* **`:Telescope help`**:  Displays a list of available pickers.

**Customization and Configuration**

Telescope’s true power lies in its configuration. It's primarily configured through Lua. Create a `telescope.lua` file in your Neovim configuration directory (e.g., `~/.config/nvim/lua/telescope.lua`). Here's a basic example:

```lua
local telescope = require('telescope')

telescope.setup {
  defaults = {
    -- Default layout for pickers
    layout_defaults = {
      width = math.floor(math.max(0, 0.6 * vim.o.columns)),
      height = math.floor(0.6 * vim.o.lines),
    },
  },
}
```

This example adjusts the default picker width and height to occupy 60% of the screen.  Experiment with these values to find what works best for you.

**Advanced Techniques**

* **Custom Pickers:**  You can create custom pickers to search for anything you can generate a list from. This requires writing Lua code to feed Telescope a list of items. This is an advanced topic, but the Telescope documentation provides excellent examples.
* **Key Mappings:**  Define custom key mappings to quickly access your most used pickers.  For example:

```lua
vim.keymap.set('n', '<leader>f', ':Telescope find<CR>', { desc = 'Find files' })
```

This maps `<leader>f` to the `:Telescope find` command.  Customize the mapping to suit your preferences.
* **Live Filtering:** Telescope filters results as you type. Use this to your advantage to quickly narrow down your search.
* **Preview Window:**  Enable the preview window to view the contents of selected files without opening them. Configure this in your `telescope.lua` file:

```lua
telescope.setup {
  defaults = {
    preview = true,
  },
}
```

**Troubleshooting**

* **`E319: Sorry, Telescope.nvim could not find the plenary.nvim`:**  Ensure `plenary.nvim` is installed correctly.
* **Slow Performance:**  If Telescope feels slow, check your file system and ensure that your search paths aren't excessively broad. Consider excluding directories from the search using the `filetypes` option.
* **Unexpected Behavior:**  Review your `telescope.lua` configuration for errors.  The Telescope documentation is your friend.
