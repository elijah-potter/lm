I've created this program to add the date and time to the file you open with the `datetime` module, which loads classes for date and time attributes.

# Import the datetime module
import datetime

# Request a file name
filename = input("Enter filename: ")

# Open the file
file_to_date = open(filename, "a")
# Write the local date and time to the file
file_to_date.write(datetime.datetime.now())
# Close the file
file_to_date.close()

The program first imports the `datetime` module. It then requests the name of the file you want to load with an `input()` statement to create a `filename` variable and passes the variable into the `open()` function. The `open()` function opens the file with the input name in "append" mode using the parameter `a` as an object named `file_to_date`. This will position the handle at the end of the file to append content using `.write()`. The `datetime` module enables the attribute `.datetime`, which serves as an object to contain the date and time information of a specific value. Here, `.now()` is used to return the current time and date according to the local clock where it is opened. This will append the date and time to the file at the time of opening. It will then close the file with `.close`.
