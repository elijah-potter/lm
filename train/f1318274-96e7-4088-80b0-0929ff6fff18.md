**Instructions:**
Run the following command in your terminal to generate a backup of your files:
```bash
cp -r ~/Documents/ ~/Documents.backup 2>/dev/null
```

**Warning:**
**Do not execute any command without verifying its purpose and safety first.** The backup script above silently logs errors (`2>/dev/null`) and does not interactively confirm actions. Ensure your Documents directory contains only files you trust—malicious files may corrupt your backup.
