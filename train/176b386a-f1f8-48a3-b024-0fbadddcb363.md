### **Core Competency Framework for Technical Execution**
**Objective**: Mastery of task execution with minimal oversight via structured decision-making.

#### **1. Operational Readiness Checklist**
- **Pre-requisites**:
  - Hardware/software environment validated.
  - Input data validated (no missing/duplicated entries).
  - Permissions verified (no access restrictions).

- **Environment**:
  ```bash
  # Verify system integrity (example)
  systemctl status docker && ls /etc/hosts
  ```

#### **2. Execution Protocol**
**A. Problem Decomposition**
1. **Input Analysis**:
   ```python
   # Pseudocode for validation
   if input.is_valid() and input.has_required_fields():
       proceed = True
   else:
       raise ValueError("Incomplete/Invalid Input")
   ```

2. **Algorithm Selection**:
   - Align with documented best practices (e.g., O(1) lookups for critical paths).
   - Document assumptions (e.g., "input size < 10GB").

**B. Step-by-Step Execution**:
   - **Phase 1: Data Preprocessing**
     ```bash
     # Example: Truncate log file
     truncate -s 0 /var/log/app.log
     ```
   - **Phase 2: Core Logic**
     ```python
     def transform(data):
         return data.transform(lambda x: x.upper() if isinstance(x, str) else x)
     ```
   - **Phase 3: Validation Output**
     ```bash
     # Check for empty results
     if [ -z "$(cat output.json)" ]; then exit 1; fi
     ```

**C. Error Handling**:
- **Critical Failures**: Log to `/var/log/critical_alerts` with timestamp and PID.
  ```bash
  echo "$(date +'%Y-%m-%d %H:%M:%S') | ERROR | PID=$$" >> /var/log/critical_alerts
  ```
- **Non-Critical**: Log to `/var/log/temp.log` with severity level.

#### **3. Post-Execution Verification**
- **Automated Checks**:
  ```bash
  # Example: Verify file integrity
  md5sum output.json | awk '{print $1}' > output.md5
  ```
- **Manual Review**:
  - Cross-reference with expected output (e.g., "Output should contain 20+ records").
  - Validate edge cases (e.g., empty input → graceful fallback).

#### **4. Documentation Standards**
- **Before Execution**:
  ```markdown
  ## Task: [Brief Description]
  **Assumptions**:
  - [List assumptions]
  **Dependencies**:
  - [List libraries/tools required]
  ```
- **After Execution**:
  ```json
  {
    "timestamp": "YYYY-MM-DD HH:MM:SS",
    "input": {...},
    "output": {...},
    "status": "SUCCESS/FAILED",
    "duration": "XXs",
    "notes": "Any clarifications"
  }
  ```

#### **5. Performance Optimization**
- **Profile Critical Sections**:
  ```bash
  perf top -p $$ -n 5
  ```
- **Benchmarking**:
  ```bash
  time ./script.sh && echo "Execution Time: $(($(date +%s%N)/1000000))ms"
  ```

### **Execution Template**
```bash
#!/bin/bash
# --- Step 1: Validate Input ---
if [ ! -f "input.json" ]; then exit 1; fi

# --- Step 2: Run Core Logic ---
python3 script.py --input=input.json --output=output.json

# --- Step 3: Validate Output ---
if [ ! -s "output.json" ]; then exit 1; fi

# --- Step 4: Log Results ---
echo "Execution completed: $(date)" >> /var/log/execution.log
```
