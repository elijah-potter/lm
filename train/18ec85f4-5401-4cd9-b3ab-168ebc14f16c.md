Title: Unexpected NullPointerException in Java Stream

Environment:
* Java Version: 17.0.5
* Operating System: macOS 13.6.3
* Editor: IntelliJ IDEA 2023.2.2

```java
import java.util.List;
import java.util.stream.Collectors;

public class StreamProblem {

    public static void main(String[] args) {
        List<String> data = List.of(
            "apple",
            null,
            "banana",
            "cherry",
            null
        );

        List<String> processed = data.stream()
            .map(s -> s.toUpperCase())
            .filter(s -> s != null)
            .collect(Collectors.toList());

        System.out.println(processed);
    }
}
```

Observed Behavior:

The program throws a `NullPointerException` on the `.map()` operation. The error message indicates a null value was encountered while attempting to call `toUpperCase()` on a string.

Expected Behavior:

The program should gracefully handle the null values within the `data` list. The `.filter()` operation should remove the null values, and the program should print a list containing only the uppercase versions of "apple", "banana", and "cherry". The expected output is:
`[APPLE, BANANA, CHERRY]`



Troubleshooting Steps:

*   Verified that the input list `data` indeed contains null values.
*   Confirmed that the `.map()` operation is attempting to call `toUpperCase()` on a string.
*   Reviewed the `.filter()` operation to ensure it correctly removes null values.
*   Examined the Java documentation for `String.toUpperCase()` to understand its behavior with null inputs.
*   Experimented with an alternative filtering approach using `Objects.nonNull()` before the map.
