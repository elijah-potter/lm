Okay, this Python code should work for you:

```
# Import the webbrowser library
import webbrowser

# Get the site name
site = input("Enter the name of the website you want to visit: ")

#
url_site = "https://www." + site + ".com"

try:
    webbrowser.get("chrome").open_new_tab(url_site)
except:
    print("That website does not follow the www.site.com format.")
    break
```

The code uses the `webbrowser` library that you'll need to send the prompt to the browser to open a new tab. It accepts the user input of the site name as `site` and appends the prefix and suffix needed to convert the site name to a URL, then passes the `url_site` URL to the `.open_new_tab()` method with the `.get()` method specifying the Chrome browser. The `try`/`except` block ensures it will only work for websites that follow the `www.sitename.com` format. If the opening attempt is unsuccessful, it will notify the user of that and end the program.
