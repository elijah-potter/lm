A miscommunication between the server and client led to an unexpected HTTP 408 **Request Timeout** response. The client's retry mechanism failed to detect the actual issue: the server had been misconfigured to drop idle connections after 30 seconds, but the real problem was a misaligned session cookie timeout (client set to 5 mins, server to 10 mins). The fix was updating the server’s session timeout to match the client’s setting, resolving the deadlock.
