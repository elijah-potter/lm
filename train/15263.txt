Past, Present, and Future Tense
In this lesson, students will use code blocks to create an interactive project where a fish Actor’s image changes depending on which tense icon (labeled “past,” “present,” and “future”) it’s touching. Coding activities include making draggable Actors, using the "switch to costume" block to change the Actor's image, and using the "broadcast" and "when I receive" blocks to change the Actor's thought bubble. Students are provided the necessary visual assets (backgrounds, costumes, Actors) and code blocks in the DIY module. After completing the DIY module, students will be asked 5 quiz questions on past, present, and future tense statements. By the end of the lesson, students will have experimented with coding concepts (e.g., simple events, loops, conditionals, conditions, motion, costume handling, messaging) while reinforcing past, present, and future tenses.
