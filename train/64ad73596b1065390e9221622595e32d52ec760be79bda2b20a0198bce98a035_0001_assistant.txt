Python is a high-level programming language created by Guido van Rossum and released in 1991. Guido prioritizes simplicity and readability, which are both distinctive features of the programming language. These features, plus Python's high versatility are among the reasons that the programming language is one of the most popular among coders. Python can be used for a variety of programming projects including data science, gaming, software development, and more. The programming language got its name from the British comedy troupe, Monty Python.
