Web pages may be retrieved from a local computer or from a remote web server. The web server may restrict access only to a private network, e.g. a corporate intranet, or it may publish pages on the World Wide Web. Web pages are requested and served from web Server (computing)|servers using Hypertext Transfer Protocol (HTTP).
Web pages may consist of files of static text and other Web content|content stored within the web server's file system (Static web page|static web pages), or may be constructed by Server-side scripting|server-side software when they are requested (dynamic web pages). Client-side scripting can make web pages more responsive to user input once on the client browser.
