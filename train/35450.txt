Unity is an open source desktop shell for the Linux platform. It was created by Canonical in collaboration with the Ubuntu community. Ubuntu founder Mark Shuttleworth originally unveiled Unity in 2010 at an Ubuntu Developer Summit in Belgium.
The Unity shell first shipped in the Ubuntu 10.10 Netbook Edition, but was later adapted to work on desktop computers. Ubuntu 11.04 is the first major Ubuntu release to use Unity as the standard operating environment on both the desktop and netbook form factors.
Unity is designed to work with a compositing window manager and requires hardware-accelerated rendering. The original netbook version of Unity was built on top of Mutter, GNOME's Clutter-based window manager. The Unity developers later abandoned Mutter—citing the performance limitations of Clutter—and rebuilt the shell as a Compiz plugin.
Canonical's team of professional designers and usability experts played a key role in defining the Unity user experience. It draws considerable inspiration from Windows and Mac OS X, but offers a unique and distinctive look and feel. Unity has a global menubar at the top of the screen and an autohiding task dock on the left-hand side of the screen. Unity also incorporates the technologies that were introduced by Ubuntu's Ayatana project, such as application indicators.
Although the first shipping versions of Unity offer considerable usability advantages over the conventional GNOME 2.x desktop, the shell suffers from many rough edges and design limitations.
