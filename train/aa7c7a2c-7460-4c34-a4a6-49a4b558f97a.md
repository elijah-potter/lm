Title: Unexpected `None` Return from `sorted()` with Custom Key

Environment:

*   Language: Python 3.11.5
*   Operating System: macOS 13.6.3 (Ventura)
*   Editor: Visual Studio Code v1.83.1

```python
data = [{'name': 'Alice', 'score': 100},
        {'name': 'Bob', 'score': 50},
        {'name': 'Charlie', 'score': 50}]

def get_name(item):
    return item['name']

sorted_data = sorted(data, key=get_name)

print(sorted_data)
```

Observed Behavior:

The `sorted_data` variable unexpectedly contains `None` as the first element. This is not a dictionary as expected, but a `None` value. The program terminates with a `TypeError` when attempting to access a property of this `None` value later in the script.

Expected Behavior:

The `sorted_data` variable should contain a list of dictionaries, sorted alphabetically by the 'name' key. The first element should be `{'name': 'Alice', 'score': 100}`.

Troubleshooting Steps:

1.  Verified the `get_name` function returns a string.
2.  Inspected the input `data` list for unexpected elements.
3.  Checked for errors in the `sorted()` function itself.
4.  Simplified the `get_name` function to a lambda expression.
5.  Verified the data types of the dictionary values.
