It seems like your division by 2 in the area formula is misplaced. According to the coordinate formula you referenced, the absolute value of the three products summed together should be divided by two. With the current code, only the final product is being divided. You can use this instead to fix the issue:

public double Area
        {
                get
                {        
                        return Math.Abs(v1.X * (v2.Y - v3.Y) + 
                        v2.X * (v3.Y - v1.Y) + 
                        v3.X * (v1.Y - v2.Y)) / 2;                        
                }
        }
