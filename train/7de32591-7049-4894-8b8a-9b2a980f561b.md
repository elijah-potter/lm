Title: Unexpected `TypeError` with List Comprehension and `sum()`

```python
# Python 3.11.5
# macOS 13.6.3
# VS Code v1.84.2
```

```python
data = [
    (1, 'a'),
    (2, 'b'),
    (3, 'c'),
    (4, 'd'),
    (5, 'e')
]

result = sum([x for x in data if isinstance(x, tuple)])
```

Observed Behavior:

A `TypeError: unsupported operand type(s) for +: 'int' and 'tuple'`
is raised. The error occurs within the `sum()` function during the
attempt to add the integer `0` (the initial value for `sum()`) to
the first tuple in the list comprehension's output.

Expected Behavior:

The code should execute without error. The list comprehension
should iterate through the `data` list and produce a list of tuples.
The `sum()` function should then attempt to sum the elements of this
list of tuples, but since `sum()` is not designed to sum tuples,
it should either return the list of tuples unchanged or raise a
more informative error.



Troubleshooting Steps:

1. Verified Python version using `python --version`.
2. Confirmed `data` contains tuples using `print(type(data[0]))`.
3. Attempted to cast the list comprehension's output to a list of
   integers, but this introduced a different error.
4. Tested the list comprehension independently to ensure it produces
   the expected output.
5. Simplified the list comprehension to only include the first element
   of `data`, which also resulted in the same `TypeError`.
