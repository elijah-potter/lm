Title: Unexpected `TypeError` with List Comprehension and `sum()`

Environment:
* Python 3.9.7
* Windows 10
* Visual Studio Code

```python
data = [1, 2, 3, 4, 5]
result = sum([x * 2 for x in data])
print(result)
```

Observed Behavior:

A `TypeError: 'generator' object cannot be interpreted as an integer`
is raised. The program terminates abruptly.

Expected Behavior:

The code should execute without error and print the value 30.
The list comprehension should produce a list of integers,
and `sum()` should correctly calculate their total.

Failed Troubleshooting Steps:

1. Verified that the `data` list contains only integers.
2. Confirmed that Python version is 3.9.7, as expected.
3. Checked for typos within the list comprehension syntax.
4. Attempted to explicitly convert the generator to a list:
   `result = sum(list([x * 2 for x in data])`
5. Tested a simpler list comprehension:
   `result = sum([x for x in data])` which worked correctly.
