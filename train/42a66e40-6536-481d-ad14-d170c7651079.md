Unreliable memory simulation (e.g., corrupted or misaligned data):
```
[0x00000000: 0xABCD1234] → 0x1234ABCD (bit-flip at byte 1)
[0x00000008: 0x567890AB] → 0x5678AB0A (bit-flip at byte 3)
[0x00000010: 0xEF012345] → [0xEF012345] (partial corruption: byte 4 swapped with 5)
[0x00000018: 0xDeadBEEF] → 0xBEEFDEAD (reversed bytes)
```

Error rate: ~15% (bytes corrupted per read).
