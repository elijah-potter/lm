I'm using Advanced Custom Fields (ACF) to create custom fields for each listing in my directory. I have a repeating section in Elementor that represents each listing. Within that section, I’m attempting to dynamically populate a heading with the value of a custom field called "listing_title" (a text field). Instead of displaying the individual "listing_title" values, every instance of the heading within the repeating section displays the *first* "listing_title" value from my entire directory. It’s as if the dynamic tag is only pulling the first entry and broadcasting it across all repeating sections. This renders the entire repeating section essentially useless, as it's displaying the same information multiple times.

*   **Cache Clearing:** I've cleared all caching plugins (WP Rocket and Cloudflare) and also purged my server-side cache. This didn’t resolve the issue.
*   **Elementor Updates:** I'm running the latest versions of both Elementor and ACF.
*   **Conflict Testing:** I deactivated all other plugins besides ACF and Elementor to rule out any conflicts. The problem persists.
*   **Reviewed Elementor Documentation:** I’ve scoured the Elementor documentation and watched several tutorials regarding dynamic tags, but I haven't found anything that addresses this specific behavior.
*   **Inspected Elementor's Output:** I've used my browser's developer tools to inspect the generated HTML and confirm that the dynamic tag is indeed being rendered, but the value is consistently the first entry.

Any insights or suggestions would be incredibly helpful. I'm happy to provide more details or screenshots if needed. Thank you in advance for your time and assistance.
