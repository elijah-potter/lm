Description: This model provides an example of using the Command Line Operator to plug programs not directly supported by Spatial Modeler Operators into a Model. The example shows a spatial model performing a reprojection process using the Command Line operator. Note that running a command generally requires input files and produces output files. Consequently, when used in a Command Line Operator, the Model has to produce a temporary file to input to the Operator and will need to write a file out. Hence the apparently “reversed” Raster Output and Raster Input operators around the Command Line operator. This pattern is really only required when embedding a Command Line operator into a larger Model process.
