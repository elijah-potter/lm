# Instructions for Task Completion

**Step 1: Data Collection**
- Gather all required input data.
- Ensure the input is complete and error-free.
- Verify input format matches expected structure (e.g., JSON, CSV, plain text).

**Step 2: Preprocessing**
- Clean raw input: remove duplicates, handle missing values, normalize formats.
- Split data into batches if necessary (e.g., for large datasets).

**Step 3: Validation**
- Validate input against predefined criteria (e.g., schema, constraints).
- Log any discrepancies for review.

**Step 4: Processing**
- Execute the specified function/module with the validated input.
- Monitor progress for critical operations (e.g., file I/O, API calls).

**Step 5: Output Generation**
- Format results according to downstream requirements (e.g., JSON, CSV, text).
- Include metadata (e.g., timestamps, version numbers).

**Step 6: Error Handling**
- Capture exceptions with tracebacks.
- Log warnings for recoverable issues.
- Notify system admins for critical failures.

**Step 7: Finalization**
- Save outputs to designated paths.
- Clean up temporary files.
- Notify completion via status log or API callback.
