public int letterCounter(String str, char letter) {

       if(str.charAt(i) == letter) {
       count++;
}
}

}

The function works by taking in a string and a letter as parameters. Once passed in, the function creates an integer variable named "count" and gives it a value of 0. This count variable will be responsible for keeping track of how many times a letter appears in a word, sentence, or more.  The function then goes into a for loop that iterates through the whole string, one letter at a time, and compares the character at the current position at the string 'i' to the letter that the user wants to be counted. If there is a match between the two, the count variable increments by 1. Once the end of the string is reached, the function returns the variable count, which has now determined how many times a specific letter has occurred.
