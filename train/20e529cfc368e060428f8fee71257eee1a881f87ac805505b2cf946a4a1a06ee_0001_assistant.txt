```
# Create a list to hold the book titles
book_titles = []

# Ask for input until "done"
while True:
    title = input("Enter a book title (or 'done' to quit): ")
    if title == 'done':
        # Quit the loop
        break
    
    # Otherwise add the title to the list
    book_titles.append(title)

# Once done, sort the list alphabetically
book_titles.sort()

# Open a file, and write each title to the file
with open("books.txt", "w") as f:
    for title in book_titles:
        f.write(title + "\n")
```

This script will first create a list called `book_titles` to hold the titles of the books. It uses a `while` loop set to `True` so that the loop will continue indefinitely until it breaks, and an `if` statement is embedded in the `while` loop so that if the user enters "done", the loop is broken. Every title the user enters in the `input()` statement is added to the list with `.append()` until the loop breaks. When broken, the code will put the list in alphabetical order using `.sort()`. The `with open()` opens a file called "books.txt" or creates one if no file is found, using `w` to put the file in write mode and `f` to define the callable variable. The `for` loop will iterate over each item in the `book_titles` list, writing each one to the file on a new line. Let me know if this works for you!
