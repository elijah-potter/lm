Title: Unexpected NullPointerException in Java Stream

Environment:
* Java: 17.0.2
* OS: macOS 13.6.1
* Editor: IntelliJ IDEA 2023.1.5

```java
import java.util.List;
import java.util.stream.Collectors;

public class StreamProblem {

    public static void main(String[] args) {
        List<String> names = List.of("Alice", "Bob", null, "Charlie");

        List<String> processedNames = names.stream()
                .filter(name -> name != null && name.length() > 2)
                .map(String::toUpperCase)
                .collect(Collectors.toList());

        System.out.println(processedNames);
    }
}
```

Observed Behavior:
The program throws a `NullPointerException` on line 6 within the stream pipeline. The exception occurs during the `map` operation.

Expected Behavior:
The stream should gracefully handle the `null` value. The `filter` operation should remove the `null` element, and the subsequent `map` and `collect` operations should proceed without error. The output should be `[ALICE, CHARLIE]`.



Troubleshooting Steps:

1. Verified that the input list contains a `null` element.
2. Added a null check within the `map` operation (did not resolve).
3. Attempted to use `flatMap` instead of `map` (did not resolve).
4. Reviewed the Java documentation for `stream.map` and `stream.filter`.
5. Tested a simpler stream pipeline with only `filter` and `collect` (null was filtered correctly).
