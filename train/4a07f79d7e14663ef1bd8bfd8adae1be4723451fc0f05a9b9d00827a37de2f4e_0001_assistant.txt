import hashlib
password = "PasswordWithNumbersAndSymbols123!@#"

def hash_password(password):
   # hash password using sha256 algorithm
    hash_object = hashlib.sha256(password.encode('utf-8'))
    hex_dig = hash_object.hexdigest()
    return hex_dig

hashed_password = hash_password(password)
print(hashed_password)

This code takes a plaintext password and outputs a SHA-256 encoded string. Note that this is a one-way hash and the original password can't be easily retrieved from it. To check that a user's password is correct you should compare the stored hash to the input hash.
