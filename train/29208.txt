There are several options available when exporting or converting Excel files to Word documents. Excel tables can be copied-and-pasted into Word files in their original formats or converted to match the Word format. Excel files also can be exported to Word in the rich text file format (.rtf), while still maintaining the column and row spacing. Links can be created between Excel tables imported into Word and the original document in which the table was created. It also is possible to save an Excel table as an image file, which can then be imported into a Word document. This article provides step-by-step instructions on the different methods to convert a table from Excel into Word.
Import an Excel Table into Word
- 1Copy and paste an Excel table into a Word file. Select the data, table or chart to be exported and select "Copy" from the options on the Formatting toolbar. Open the Word file the data is to be exported to, and select the "Paste" option from the Formatting toolbar. The data has been exported into Word.
- 2Use the "Paste Options" feature to paste the table, chart or data so that it is formatted especially for Word. Click the "Paste Options" button that appears next to the imported object. Choose the ""Match Destination Table Style" option from the pull-down menu. The Excel data has been imported.
- 3Use the "Paste Options" feature to paste the table, chart or data so that it is formatted in rich text format with tabs to delineate between columns. Click on the "Paste Options" button located near the imported object. Select the "Keep Text Only" option from the pull-down menu. The data has been exported without borders or formatting.
- 4Use the "Paste Options" feature to create a link to the data between the Word document and the original Excel file in which the data or table was created. Click the "Paste Options" button that appears next to the imported object. Select the "Match Destination Table Style," or the "Link to Excel" or "Keep Source Formatting and Link to Excel" option from the pull-down menu. A link between the 2 files has been established.
Import an Excel Chart into Word as a Bitmap Image File
- 1Import an Excel chart as a bitmap image file. Click on the "Paste Options" button appearing next to the imported chart. Select the "Save as image" option from the pull-down menu. The chart has been inserted into Word as an bitmap image file.
Import an Excel Table or Chart into Word as a JPEG Image File
- 1Take a screen-shot or print-screen of an Excel table or chart, and export it into Word as an image file. Maximize the Excel application window and zoom in to the chart so that all of the information is still visible. Hold down the control key on the computer keyboard and press the "Print Screen" key located in the top row of keys on the right side of the keyboard.
- Save an image of the chart as a JPEG file. Open the MS Paint program, typically located in the "Accessories" folder which can be accessed from the start menu, under "All Programs." With the image visible in the MS Paint application, select the file tab, then the "Save As" option, and choose "JPEG." A JPEG image of the chart has been saved.
- Import the image into a Word document. Open a Word document and click and drag the image into the file, Alternatively, click the "Insert" option from the menu bar and select the "Picture from file" option from the pull-down menu. A JPEG image has been imported into the intended Word file.
