Bytes::Random - Perl extension to generate random bytes.
use Bytes::Random; my $bytes = random_bytes( $number_of_bytes );
Bytes::Random provides the
random_bytes($num) function. It can be used anytime you need to generate a string of random bytes of a specific length.
Returns a string containing as many random bytes as was requested.
