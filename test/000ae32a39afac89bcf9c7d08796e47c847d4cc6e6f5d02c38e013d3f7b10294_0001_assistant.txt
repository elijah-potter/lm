def calculate_tax_total(initial_price, tax_percent):
  tax_amount = initial_price * (tax_percent / 100)
  total_price = initial_price + tax_amount
  print(f"Total Price: ${total_price:.02f}")

# Set price and tax percentage
initial_price = 100.00
tax_percent = 5.0

calculate_tax_total(initial_price, tax_percent)

This creates a function that will accept an original price of initial_price and a tax rate of tax_percent, calculate the taxes as tax_amount by multiplying the initial_price by the tax_percent divided by 100, and add tax_amount to initial_price to get a total of total_price. It will then print the total with two decimal places using :.02f formatting. The example shows an initial price of $100.00 and a tax rate of 5.0%. The initial_price and tax_percent values can be replaced with the values for which you want to find the total price.
