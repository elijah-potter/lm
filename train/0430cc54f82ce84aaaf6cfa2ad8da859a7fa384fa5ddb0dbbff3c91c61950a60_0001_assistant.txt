Here is a way to do that using matplotlib in a Jupyter environment:

import matplotlib.pyplot as plt
import numpy as np
x = np.arange(-20,21)
y = x**2+4*x+4
plt.plot(x,y)
plt.show()

This code imports the matplotlib and numpy modules to prepare the plotting environment, then creates the specified range of values of x using np.arange. It then defines the given function (y) and plots the graph of values of y against values of x. Most times in Jupyter interfaces, the plot will be displayed even without the plt.show() line once you run the cell containing the plot command. The plt.show() command is more often used to display the plot in non-Jupyter interfaces.
