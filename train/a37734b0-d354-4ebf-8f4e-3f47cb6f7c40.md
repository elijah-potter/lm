The abandoned plan was to implement a real-time data pipeline for IoT device telemetry processing, involving cloud integration with AWS IoT Core and Apache Kafka. Initial progress was promising with a prototype deployed in a test environment, but budget cuts forced a pause in development. The team shifted focus to a more cost-effective solution using on-premises message brokers like RabbitMQ and local data processing with Python scripts. Technical constraints, such as latency requirements not being met with the initial architecture, and resource allocation challenges further stalled progress. The project was officially abandoned after three months due to shifting priorities and lack of sufficient funding.
