This course is an introduction to web site development. That means we will be starting at the beginning with the basics, and working up from there. If you do have some experience with HTML and programming, there is still plenty to learn. The objective is to learn something new, gain some experience, practice some new skills, ask your questions, share your work and enjoy learning along with everyone in the class.
You are here because you want to learn HTML and create web pages. All web pages are built using a few essential elements. Through practice assignments, reading and discussions, you will learn to develop entire web sites and control the appearance, formatting and contents of a site using these elements.
The key skills of web development are teamwork, attention to detail, debugging, project management, distributed version control, the agile process, accessibility and usability, user needs analysis, user testing, and much more. You will have an opportunity to practice all of these as well.
* explore the HTML language formatting and element structures
* use the basic HTML elements for a basic web page
