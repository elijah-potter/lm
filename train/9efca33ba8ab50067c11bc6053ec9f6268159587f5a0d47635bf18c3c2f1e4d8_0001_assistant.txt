Here's a Java function that calculates the running sum of a one-dimensional array.

 public int[] runningSum(int[] nums) {
        int [] sumArray = new int[nums.length];
        int sum = 0;
        for(int i = 0; i < nums.length; i++){
            sum = sum + nums[i];
            sumArray[i] = sum;
        }
        return sumArray;
    }

1. The function creates a new array called "sumArray" that is initialized to the length of the input array. This will eventually be the array that gets returned at the end.
2. A variable of type integer named 'sum' was created and initialized to 0. This variable will serve as the running sum as we traverse the array.
3. A for loop is created that iterates through the 'nums' array. Within the loop, the 'sum' variable adds what the current 'sum' is to the current value of 'nums[i]'. It then places the current sum at position 'i' in the array created in step 1, 'sumArray'.
4. After the for loop reaches the end of the loop, it returns 'sumArray', which should contain the running sum of the input array.
