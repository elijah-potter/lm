Each of the inner arrays needs to be initialized with the new operator, and the elements should be contained in curly braces, not square brackets. The following would be a good approach:

var jaggedArray = new int[][]
{
    new int[] { 1, 2, 3 },
    new int[] { 4, 5 },
    new int[] { 6, 7, 8, 9 }
};

You can also shorten this by omitting the new operator like this:

int[][] jaggedArray = 
{
    new int[] { 1, 2, 3 },
    new int[] { 4, 5 },
    new int[] { 6, 7, 8, 9 }
};

I hope that helps!
