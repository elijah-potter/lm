The **"Supercharged" Command-Line Loopback Mode (SCL-LM)**:
A non-trivial macro system for CLI tools that bypasses native shortcuts by encoding multi-key sequences (e.g., `Ctrl+Alt+Delete`) into a single, non-verbatim token (e.g., `~!SYSRESET~`). Works across shells (bash, zsh, fish) via `readline` hooks, replacing `Ctrl+C` with `~!STOP~` while preserving escape sequences for scripting.

**Example Output (from a hypothetical CLI tool):**
```plaintext
SCL-LM: Enabled for /bin/bash. Use `~!SHORTCUTS~` to list active macros.
~!SYSRESET~: Replaces Ctrl+Alt+Delete; requires root privileges.
```
