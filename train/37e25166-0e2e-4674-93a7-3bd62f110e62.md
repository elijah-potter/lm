Title: Unexpected `TypeError` when Passing Tuple to Function

```python
# Python 3.11.5
# macOS 13.6.3
# Visual Studio Code

def process_data(point):
    """Calculates the distance from the origin."""
    x, y = point
    return (x**2 + y**2)**0.5

data = (3, 4)
result = process_data(data)
print(result)
```

Observed Behavior:

A `TypeError: 'tuple' object is not iterable` is raised on the line `x, y = point`. The program terminates.

Expected Behavior:

The `process_data` function should correctly unpack the tuple `data` into variables `x` and `y`, calculate the distance, and print the result (5.0).



Troubleshooting Steps:

1. Verified Python version to ensure compatibility.
2. Confirmed the data variable is indeed a tuple.
3. Examined the function signature for incorrect parameter types.
4. Checked for shadowing of the `point` variable.
5. Attempted to explicitly convert the tuple to a list.
