Audio Mixing is the process of combining one audio's content with another. Audio mixing can be used to mix a song with vocal, create special audio effects for movie editing project or create your own DJ-style music. You can use Dexster software to mix the currently edited audio's content with another audio file or audio fragment that being copied in the memory buffer. To use the software's audio mixing feature, click open to load an audio (MP3, WAV, WMA, OGG, M4A, AAC, FLAC) file. Dexster will then load the audio's content on the editing panel. From the editing panel, select the waveform area that you intend to mix. Click on the Edit menu, select Mix Paste from file and select an audio file for mixing. The software will present you with audio mixing configuration where you can adjust the audio amplification for both audio’s content. Then press OK to mix the audio.
