centos - Computer Definition
(Community ENTerprise OS) A popular Linux distribution that is built from the same open source modules in Red Hat Enterprise Linux, which is a commercial product. CentOS is widely used for websites in cloud computing environments. Since Linux is open source, the OS can be copied and distributed without infringing on any distributor's rights as long as any proprietary software of that distributor, such as an installation program, is not copied with it. For more information, visit www.centos.org. See Linux.
