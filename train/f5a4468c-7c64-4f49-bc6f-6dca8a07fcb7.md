Title: Python List Comprehension Appending Unexpected Values

```python
# Python 3.11.5
# macOS 13.6.3
# Visual Studio Code

def process_data(data):
    result = [x * 2 for x in data if x % 2 == 0]
    return result

my_data = [1, 2, 3, 2, 1, 2]
processed_data = process_data(my_data)
print(processed_data)
```

Observed Behavior:

The code prints `[4, 4, 4]`. It appears that the list comprehension
is appending the value `4` three times, despite only two even
numbers existing in the input `my_data`.

Expected Behavior:

The code should print `[4, 4]`, reflecting the doubling of the two
even numbers (2 and 2) present in the input list `my_data`.

Troubleshooting Steps:

1. Verified that the input list `my_data` contains only integers.
2. Confirmed that the modulo operator (%) is functioning as expected.
3. Inspected the list comprehension syntax for typographical errors.
4. Tested with a simplified input list: `[2, 2]`.  The result
   remains `[4, 4]`.
5. Examined the scope of variables within the function to ensure
   no external factors are influencing the output.
