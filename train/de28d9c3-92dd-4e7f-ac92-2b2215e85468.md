The unspoken rule in the server room was never explicitly stated, but the engineers knew it well: **"Never let a server reboot without a log of the last shutdown status."** Yet, it was broken daily—someone would power down a machine mid-task, a cable slipped, or a misplaced keyboard shortcut sent a server into a forced shutdown. The logs would be empty or corrupted, and no one mentioned it. The silence was the only compliance. The real violation was in the absence of any resistance.
