It is the “readable” phase of the World Wide Web with flat data.In web 1.0, the interaction between the users and sites is restricted.Web 1.0 is a an information portal from where you can receive information but you cannot make comments and post reviews.
It is the “writable” phase of the World Wide Web with interactive data. Web 2.0 facilitates interaction between web users and sites, so it allows users to interact freely with each other. Web 2.0 encourages participation, collaboration, and information sharing. Youtube, Wiki, Flickr, Facebook are some of the examples of Web 2.0.
It is the “executable” phrase of Word Wide Web with dynamic applications, interactive services. With Web 3.0. “machine-to-machine” interaction has been developed. In Web 3.0, computers can interpret information like humans and intelligently generate and distribute useful content.
