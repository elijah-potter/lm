The comparison below outlines key differences between **binary search** and **linear search** in algorithms:

| **Aspect**          | **Binary Search**                          | **Linear Search**                        |
|---------------------|-------------------------------------------|------------------------------------------|
| **Data Type**       | Requires **sorted** array/list             | Works on any unsorted data                |
| **Time Complexity** | **O(log n)** (efficient for large datasets) | **O(n)** (slower for large datasets)       |
| **Search Strategy** | Divides search space in half iteratively   | Checks each element sequentially          |
| **Use Case**        | Optimal for static, sorted data            | Simple, works everywhere                  |
| **Memory Access**   | Uses **random access** (direct indexing)   | Uses **sequential access** (one by one)   |

---
**Key Insight**: Binary search is faster but requires sorted input; linear search is flexible but inefficient for large datasets.
