The best approach would be to import the Pandas module to use Pandas DataFrames to combine the 3 Excel files into one. Here is the example code:

import pandas as pd

df1 = pd.read_excel('file1.xlsx')
df2 = pd.read_excel('file2.xlsx')
df3 = pd.read_excel('file3.xlsx')

df = pd.concat([df1, df2, df3])

df.to_excel('combined.xlsx', index=False)

The result is the three files read into a new file called "combined.xlsx".
