**Step-by-Step Guide: Basic File Backup**

1. **Collect Source Files**
   Identify and list all files you wish to back up. Include:
   - Text documents (.txt, .doc, .docx)
   - Images (.jpg, .png, .gif)
   - Configuration files (.ini, .conf, .cfg)
   - Log files (.log, .txt) from active directories

2. **Design Backup Location**
   Choose a secure, external storage (USB drive, cloud service, or network drive). Label the destination with a timestamp:
   ```
   BACKUP_YYYYMMDD_HHMMSS
   ```

3. **Backup Method A: Manual Copy**
   - Open the source directory in File Explorer (Windows) or Finder (Mac).
   - Right-click → *Copy* or *Drag & Drop* files to the backup location.

4. **Backup Method B: Scripted (PowerShell/Bash)**
   **Windows (PowerShell):**
   ```powershell
   Get-ChildItem -Recurse "C:\SourceDir" | Copy-Item -Destination "D:\Backup\BACKUP_20241025_143000" -Force
   ```

   **Linux/Mac (Bash):**
   ```bash
   tar -czvf BACKUP_20241025_143000.tar.gz /path/to/source
   ```

5. **Validate Backup Integrity**
   - Compare file sizes between source and backup.
   - Verify critical files (e.g., `config.json`, `logs_2024.txt`) exist in the backup.

6. **Automate (Optional)**
   Schedule backups via:
   - **Windows Task Scheduler** (cron equivalent)
   - **Linux Cron Job**: `crontab -e`
     ```
     0 2 * * * /path/to/backup_script.sh
     ```

7. **Documentation**
   - Maintain a log file (`backup.log`) with timestamps and errors.
   - Store checksums (e.g., `md5sum` for Linux) of critical files in backup metadata.

8. **Test Recovery**
   - Periodically restore a sample file from backup to ensure data integrity.
   - Document test results in the log.

9. **Secure Backup**
   - Encrypt sensitive files using `7-Zip` (Windows) or `gpg` (Linux/Mac).
   - Example (7-Zip):
     ```
     7z a -p"password" BACKUP_encrypted.zip BACKUP_20241025_143000.zip
     ```
