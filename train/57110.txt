I was thinking about the grammatical usage of the words run and ran on my run today. I think this is an often confused word; even I get the words confused sometimes and I’m a runner.
Run can be used in past and present tense.
Ran is used in past tense only.
Understanding when to use run or ran is easier when you see it in a sentence.
Run example sentences:
“I run to stay in shape.”
“I went on a run over my lunch break.”
“I have run four marathons in my life.”
Ran example sentences:
“I ran a 5k on Saturday.”
“You ran so fast at the track meet!”
