**Instructions:**
1. Open your text editor and create a new file named `config.txt`.
2. Add the following settings in the file:
   ```
   [server]
   host=localhost
   port=3000
   timeout=10s
   ```

**Warning:**
- **Do not modify the `timeout` value below `5s`**—it may cause connection timeouts and application crashes.
- Ensure the file is saved with **read-only permissions** for sensitive data to prevent unauthorized edits. If you're unsure how to do this, use:
  ```bash
  chmod 644 config.txt
  ```
