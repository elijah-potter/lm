Title: Python List Comprehension Produces Unexpected Tuple

```python
# Python 3.11.5
# macOS 13.6.3 (Ventura)
# VS Code v1.83.1

def process_data(data):
    return [(x, x*2) for x in data]

my_list = [1, 2, 3]
result = process_data(my_list)
print(result)
```

Observed Behavior:

The code produces a list of tuples: `[(1, 2), (2, 4), (3, 6)]`. This is the intended outcome. However, subsequent code relying on the elements within `result` being individual integers fails because they are unexpectedly tuples.

Expected Behavior:

The list comprehension should produce a list of integers, where each integer is the original value from `my_list` followed by its double. The `result` variable should contain `[2, 4, 6]`.

Troubleshooting Steps:

1. Verified Python version to ensure compatibility.
2. Examined the list comprehension syntax for errors.
3. Confirmed the input data type (`my_list`) is correct.
4. Checked for unintended side effects in the surrounding code.
5. Inspected variable scope to rule out shadowing.
