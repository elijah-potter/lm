A **single vulnerability** in an authentication system, exploited via a misconfigured API endpoint (`/login?token=admin`).
**Target:** High-value corporate database backups stored in an unencrypted S3 bucket.
**Trigger:** A phishing campaign sends a fake login page mimicking a well-known cloud provider, tricking users into submitting credentials via the rogue endpoint.
**Impact:** The attacker extracts and decrypts the backups, leading to a full data breach within 48 hours.
**Exploit vector:** Zero-day flaw in a third-party SDK used for authentication, allowing bypassing rate limits when submitting the same token repeatedly.
**Recovery challenge:** The compromised token was shared across multiple systems before detection.
