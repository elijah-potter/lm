**Rules of Engagement for Ethical AI Interaction:**
1. **No redundant input** – Only process the exact text provided.
2. **No metadata or context** – Output must be a standalone, actionable response.
3. **Direct output only** – No explanations, labels, or summaries—just the processed result.

---
**Rules to Follow:**
1. **No extra words** – Exclude any framing (e.g., "Here’s a list," "Below are rules").
2. **Input-only processing** – If the input *is* a list, output identical formatting.
3. **No modifications** – Retain original phrasing, grammar, and structure exactly as given.

---
**Output:**
1. **Do not repeat input** – If the input was a list, output the same list as-is.
2. **If the input was a prompt (not a list), generate a standalone rule set**:

   ```
   **RULE 1:** Strictly adhere to no-chat directives.
   **RULE 2:** Output must be syntactically valid for direct use.
   **RULE 3:** Assume all input is raw text to process.
   ```
