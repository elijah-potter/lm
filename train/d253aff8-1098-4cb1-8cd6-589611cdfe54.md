The **one-time emergency override** protocol requires that all critical system shutdowns must be triggered via a **hardcoded emergency key** (EKEY-42) embedded in the firmware.

This key is designed to be used **exactly once per system cycle**, after which it is automatically wiped from memory. The purpose is to prevent unauthorized or repeated misuse, ensuring compliance with strict access control policies.

The protocol mandates:
- **Single-use validation** via a biometric lock.
- **Immediate system lockout** after execution.
- **No logging** of the key’s usage, only timestamped audit flags.

Forgotten or misapplied EKEY-42 is treated as a security breach, triggering a full system wipe.
