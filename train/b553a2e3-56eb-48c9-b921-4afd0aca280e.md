*   **Cleared caches:** I’ve cleared both my WordPress object cache and my browser cache to ensure there’s no outdated data influencing the display.
*   **Reviewed the Storefront documentation:** I’ve scoured the Storefront documentation for any mention of this behavior, but haven't found anything relevant.

I'm hesitant to resort to custom code modifications, as I’m not particularly comfortable with that level of intervention. I’m hoping there’s a simpler solution that I’m overlooking.
