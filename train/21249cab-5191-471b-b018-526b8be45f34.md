Title: Unexpected `nil` Value with Ruby Hash Iteration

Environment:
* Ruby: 3.2.2
* OS: macOS 13.5.1 (Ventura)
* Editor: VS Code 1.83.0

```ruby
data = {
  "a" => 1,
  "b" => 2,
  "c" => nil,
  "d" => 4
}

data.each do |key, value|
  puts "Key: #{key}, Value: #{value}"
end
```

Observed Behavior:

The program outputs the following:

```
Key: a, Value: 1
Key: b, Value: 2
Key: c, Value:
Key: d, Value: 4
```

Note the empty line for the key "c." The program does not print "Value: nil" as might be expected.

Expected Behavior:

The program should print "Value: nil" when iterating over the hash and encountering the key "c," which is associated with a `nil` value. The output should be:

```
Key: a, Value: 1
Key: b, Value: 2
Key: c, Value: nil
Key: d, Value: 4
```

Troubleshooting Steps:

1. Verified the Ruby version using `ruby -v`.
2. Inspected the `data` hash definition for typos.
3. Checked for unintended variable shadowing.
4. Experimented with different iteration methods (e.g., `each_pair`).
5. Searched the Ruby documentation for `nil` handling in hashes.
