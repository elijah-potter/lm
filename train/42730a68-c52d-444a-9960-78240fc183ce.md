Title: Unexpected `TypeError` when using `collections.Counter`

Environment:
* Python: 3.11.5
* Operating System: macOS 13.6.3 (Ventura)
* Editor: Visual Studio Code v1.83.1

```python
from collections import Counter

data = [1, 2, 1, 1, 2, 1, 2, 1, 1, 1]
counts = Counter(data)
print(counts[3])
```

Observed Behavior:

The code raises a `TypeError: unhashable type: 'int'`.

Expected Behavior:

The code should print `0`, as the integer `3` is not present
in the `data` list. The `Counter` object should return 0 when
attempting to access a non-existent key.



Troubleshooting Steps:

1. Verified Python version matches expected version.
2. Confirmed `collections.Counter` is correctly imported.
3. Checked for any shadowing of `Counter` with another variable.
4. Examined the `data` list for unexpected data types.
5. Attempted to use `counts.get(3)` instead of `counts[3]`.
