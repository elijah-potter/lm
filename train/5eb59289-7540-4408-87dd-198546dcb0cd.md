Here are key distinctions between **binary search trees (BSTs)** and **heaps**:

- **BST**:
  - Enforces left ≤ parent < right (or similar strict ordering).
  - Supports efficient O(log n) search, insert/delete via in-order traversal.
  - Unbalanced BSTs degrade to O(n) performance.

- **Heap**:
  - Complete binary tree with parent ≥ child (min-heap) or parent ≤ child (max-heap).
  - Primarily used for priority queues (extract-min/max in O(log n)).
  - No ordering guarantees between siblings; no search capability.
