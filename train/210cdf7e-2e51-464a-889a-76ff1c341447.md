Comparison between **binary search tree (BST)** and **balanced binary search tree (BBST)**:

| **Aspect**          | **BST**                          | **BBST (e.g., AVL, Red-Black)** |
|---------------------|----------------------------------|--------------------------------|
| **Balancing**       | Unbalanced (can degenerate into a linked list). | Always balanced via rotations. |
| **Time Complexity** | Worst-case: O(n) (degenerate).  | Guaranteed O(log n) for insert/search/delete. |
| **Operations**      | O(h) average, O(n) worst-case. | O(log n) for all operations. |
| **Use Case**        | Simple cases where balance is not critical. | Critical for performance-sensitive applications. |

Key difference: **BBST ensures log-time complexity by maintaining balance**, while BST does not guarantee it.
