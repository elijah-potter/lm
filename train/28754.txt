The Unsinkable Fate
Our Entry provides the user with information about the Titanic. It gives a picture tour to give the user a idea of what it looked like. The "Did You Know" page provides the user with lots of interesting facts. The activities page provides the user a fun way of learning important words, and provides the user with a fun way of learning Morse code. The code that the Titanic used. The educational objective is to provide the user with a fun and interesting way to learn facts and figures about the Titanic. Most classes do not spend much time if any on learning about the Titanic. This site would provide a social studies class a way of learning the information quickly. It would allow the student to get out of the usual routine of the classroom and be able to learn the information by just reading and browsing through our site.
