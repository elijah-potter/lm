### **User Guide: How to Navigate the Confusing Interface**

#### **1. Starting the Application**
- Press `Ctrl+Alt+X` to launch.
- A **blinking question mark** appears at the center of the screen.
- **No further instructions**—click the question mark.

---

#### **2. The Dashboard**
- The **top bar** has no labels but shows:
  - A **red circle** (status: "ERROR" if anything is wrong).
  - A **yellow triangle** (means "press this").
- Click the yellow triangle to reveal:
  - **Three icons** (top-left to bottom-right):
    1. A **folder** (opens a menu with no subtext).
    2. A **gear** (clicks and does nothing).
    3. A **magnifying glass** (searches for "Nothing Found").

---

#### **3. The Main Menu**
- If you click the folder icon, a dropdown appears with:
  - **"Menu"** (clicks to open a new menu).
  - **"Options"** (shows a list of checkboxes labeled **"Enable Debug Mode"** and **"Disable Auto-Save"**).
- **Enable Debug Mode** makes the interface turn **pink**.
- **Disable Auto-Save** causes the program to crash silently.

---

#### **4. The Workspace**
- The default workspace is a **grid of 3x3 empty cells**.
- To interact:
  - **Hover over a cell**—a **glowing outline** appears for **1 second**.
  - **Click and drag** to select multiple cells (but they all turn **blue**).
  - **Double-click a cell** to see a pop-up:
    - *"What do you want to do?"* (no options, just a button labeled **"Exit"**).

---

#### **5. File Management**
- To open a file:
  1. Press `Ctrl+Shift+Z`.
  2. A window titled **"Select File"** opens with no file list.
  3. Click **"OK"** to import a **randomly generated file** named:
     - `"data_<random_number>.txt"` (e.g., `data_42.txt`).
  4. The file contains **garbled text** (e.g., `"?@#$%^&*"`).

---

#### **6. Advanced Features**
- **Shortcut: `Ctrl+Alt+Z`**
  - Opens a **"History"** window showing:
    - **3 entries** (all identical: `"Last action: Nothing"`).
  - Clicking an entry does **nothing**.

- **Shortcut: `F12`**
  - Opens a **"Help"** window with the text:
    > *"Use this to find help. Press F12 again to exit."*

---

#### **7. Saving & Exporting**
- **Save manually**:
  - Go to **Options > Save As** (top menu).
  - Enter a filename (e.g., `"MyProject"`).
  - Click **"Save"**—the file is saved as `MyProject_<timestamp>.json`.
  - The file contains **empty JSON** (e.g., `{}`).

- **Export**:
  - Go to **File > Export** (bottom menu).
  - Select **"Format"** (shows **"Plain Text"** and **"Binary"**).
  - Click **"Export"**—the output is a **randomly generated text file** with no meaningful content.

---
#### **8. Common Errors**
| Error Message | Solution |
|---------------|----------|
| **"Invalid selection"** | Click any cell. |
| **"Permission denied"** | Enable Debug Mode (red circle → pink). |
| **"File not found"** | Generate a new file (`Ctrl+Shift+Z`). |
| **"System busy"** | Wait **5 seconds**, then try again. |

---
#### **9. Troubleshooting**
- **If the program freezes**:
  - Press `Ctrl+Alt+Esc` to open the **"Task Manager"**.
  - Click **"Close All"** (no confirmation dialog).

- **If you lose data**:
  - Go to **Options > Restore Default** (but this does nothing).

---
#### **10. Quitting the Application**
- **Graceful exit**:
  - Go to **Help > Exit** (bottom menu).
  - A confirmation dialog appears: *"Are you sure you want to quit?"* (click **"Yes"**).
- **Force quit**:
  - Press `Ctrl+Alt+Delete` → **"End Task"** the application.

---
### **Pro Tips**
- **Use Debug Mode** to see hidden features (e.g., the pink cells).
- **Ignore warnings**—they’re just animations.
- **The "Help" section** is a scam—don’t click it.
