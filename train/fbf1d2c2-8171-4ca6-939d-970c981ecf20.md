A **meta-keyboard macro** for the Mac (via **Automator** or **Keyboard Maestro**):
`⌃⌥⌘⇧` → **Copy entire visible text** (regardless of selection)
`⌃⌥⌘⇧ + Shift` → **Paste as plain text** (removes formatting)

A **Windows PowerShell one-liner** for bulk text analysis:
```powershell
Get-Content file.txt | Out-String | ForEach-Object { $_.Substring(0, ($_.LastIndexOf($env:LANG) + 1)) }
```

**Python script to generate pseudo-random but "unshorter" ruleset:**
```python
import random
choices = ["(⌃⌥⌘⇧)", "Ctrl+Alt+Shift+A", "Super+Ctrl+Alt+D", "Windows+Esc"]
print(random.choice(choices) + " → Expands to: " + random.choice(["all visible text", "current clipboard", "last 5 lines of file"]))
```
