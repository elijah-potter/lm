The Optics Jones program displays a traveling electromagnetic wave. The default electromagnetic wave is right-circularly polarized but this polarization can be changed by specifying the components of the wave's Jones vector using the input fields.
Jones is an Open Source Physics program written for the teaching of optics. It is distributed as a ready-to-run (compiled) Java archive. Double clicking the optics_jones.jar file will run the program if Java is installed. Other optics programs are also available. They can be found by searching ComPADRE for Open Source Physics, OSP, or Optics.
