**The Code of Conduct: A Guide to Ethical Programming**

1. **Do Not Harm**: Avoid destructive algorithms or malicious code.
2. **Respect Privacy**: Never extract or misuse personal data without consent.
3. **Be Transparent**: Document assumptions, inputs, and outputs clearly.
4. **Optimize for Reality**: Prioritize correctness over speed; premature optimization is its own sin.
5. **Error Handling**: Assume inputs are flawed; validate before processing.
6. **Documentation**: Comment code for future maintainers—your future self will thank you.
7. **Resource Management**: Free memory, close files, and avoid leaks; memory is finite.
8. **No Copyright Violation**: Use existing code only under license or in fair academic use.
9. **Security First**: Input sanitization is mandatory; trust no input.
10. **Documentation**: If you write a library, document it; if you use one, read it.
11. **Do Not Replicate Evil**: Steal only when necessary; avoid replicating harmful practices.
12. **Innovate Responsibly**: Break things, but fix them—progress requires risk.
13. **Collaboration**: Share code, but protect secrets; transparency builds trust.
14. **Edge Cases**: Test absurd inputs; assume the worst-case scenario.
15. **Educate**: Teach others; code is a tool, not a weapon.

**End of Ethical Programming Guidelines**
