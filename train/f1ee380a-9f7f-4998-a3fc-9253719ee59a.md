A **meta-feature** in some modern IDEs (e.g., JetBrains IDEs) allows defining **custom keybindings** for arbitrary text. For example, you could create a shortcut to expand or compress a block of text without altering its length. Example:

```plaintext
// Shortcut: Alt+Shift+D
// Expands to (but doesn’t change content):
//   TODO: [Insert detailed comments here]
//   [Code block follows]
```

The "shortcut" is conceptual—it’s not shorter in bytes but enables faster editing by reducing cognitive load. This is often called a **"macro"** or **"custom action"** in the software’s configuration.
