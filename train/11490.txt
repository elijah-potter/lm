In Chapter 2–Chapter 4 you learned how bit patterns can be used to represent data. And in Chapter 5–Chapter 7 you learned how bits can be implemented in hardware and used to perform computations. In this Chapter you will see some machine code (bit patterns) that are represented by assembly language instructions. This will only be an introduction. You will need to consult ARM manuals ( e.g., [A.1.1], [A.1.2]) for all the details. We will examine some common operations—assignment and branching.
