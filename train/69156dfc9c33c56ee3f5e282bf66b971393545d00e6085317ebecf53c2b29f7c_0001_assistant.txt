This type takes two type parameters, an object O and a type NotAssignableTo, and resolves to the keys in O whose values are not assignable to NotAssignableTo. It does this by creating a mapped type from O where for each key in O, the corresponding type is either never if its value is assignable to NotAssignableTo, or the value itself if it is not. The type then indexes the mapped type with the keys of O to produce a union of all of the mapped type's values, resulting in a union of all values that are not assignable to the type NotAssignableTo.
