How to Rewire a Lamp

Remove the Old Socket
- Before starting, make sure the lamp is not plugged in.
- Using a screwdriver, press the sleeve of the socket out.
- If the socket has a "press here" inscription, press your thumb on the inscription and lift the sleeve off.

Cut the Old Wires
- Pull the socket up, then use the wire cutter to cut/disconnect the old wires. 
- Flip the lamp over, then unscrew the nut from the bottom of the lamp base. 
- Pull the thread up and remove the old socket. 
- Pull the cord out of the bottom of the lamp.

Install the New Lamp Cord
- Feed the new lamp kit cord through the hole in the bottom of the lamp and out through the top.
- Attach the new socket.

Split the Wires and Knot the Cords
- Using the wire cutters, split the first 2" of each wire by cutting along the wire's groove. 
- Using the wire cutters, remove approximately 1/2" of the insulation from each wire. 
- Tie the split cords using an underwriter's knot. To do this, make a loop with each wire then feed the opposite color wire through each loop to create a figure eight. Note: Check the lamp kit's instructions for an illustration.

Connect the Wires
- Using the screwdriver, loosen the screws on either side of the new socket. Note: The brass is for hot and the silver is for neutral. 
- Check lamp kit instructions to determine which wire is hot.
- Wrap the hot exposed wire around the brass (hot) screw on the socket. 
- Wrap the other wire around the silver (neutral) screw.
- Using the screwdriver, tighten the screws to hold the wires in place.

Snap the Sleeve On and Test
- Slide the sleeve back onto the socket until it snaps into place. 
- Test the wire by plugging it into an outlet.
