The education culture is adapting more and more electronic means of information to teach and learn different area. The inspiration behind the development of this software is to increase student interest in learning history by developing an interactive GIS application. The tool is mainly anticipated for the use of students of Helix High School. The tool provides the functionality to describe data related to "Efforts made towards Globalism" on a map with several geographical features. The tool also has external links to the internet for further reading, as well as a visually pretty GUI to help students to interact with it and learn history easily. Usage of this tool would help to motivate students to learn history related topic effortlessly, which usually students find a little bit mind-numbing.
