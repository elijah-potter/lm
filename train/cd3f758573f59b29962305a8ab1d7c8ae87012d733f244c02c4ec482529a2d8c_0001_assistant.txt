Absolutely! Here is code that uses the numpy library to find the eigen values and eigen vectors:

import numpy as np

def compute_eigen(matrix):
    # Compute the eigenvalues and eigenvectors
    eigenvalues, eigenvectors = np.linalg.eig(matrix)
    
    # Return the eigenvalues and eigenvectors
    return eigenvalues, eigenvectors

In this code, the argument "matrix" is a square matrix (nxn) generated using numpy.array(),
