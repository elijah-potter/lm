Title: Unexpected `None` Return from `sorted` with Custom Key

Environment:

*   Python 3.11.5
*   Windows 10
*   VS Code 1.83.1

```python
data = [
    {"name": "Alice", "score": 100},
    {"name": "Bob", "score": 50},
    {"name": "Charlie", "score": 50},
    {"name": "David", "score": 100}
]

def get_score(item):
    return item["score"]

sorted_data = sorted(data, key=get_score)

print(sorted_data)
```

Observed Behavior:

The `sorted` function returns `None` instead of a sorted list of dictionaries. The program terminates without further error after the `print` statement is reached.

Expected Behavior:

The `sorted` function should return a new list containing the dictionaries from `data`, sorted in ascending order based on the "score" key. The output should be:

```
[
    {'name': 'Bob', 'score': 50},
    {'name': 'Charlie', 'score': 50},
    {'name': 'Alice', 'score': 100},
    {'name': 'David', 'score': 100}
]
```

Troubleshooting Steps:

1.  Verified Python installation integrity with `python --version`.
2.  Confirmed that the `get_score` function returns a number.
3.  Simplified the `get_score` function to `lambda item: item["score"]`.
4.  Checked for type errors within the `data` list.
5.  Reviewed the Python documentation for `sorted` for known issues.
