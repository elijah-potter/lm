A misinterpreted instruction could result in unintended outcomes. Example:
`"Sort the file list by last modified date in reverse order."`
Misread as:
`"Sort the file list by the last character in the filename in reverse order."`

Result:
`/path/to/file1.txt /path/to/file2.pdf /path/to/file3.jpg /path/to/file17.png` → **Sorted by last character (reverse alphabetical):**
`/path/to/file17.png /path/to/file3.jpg /path/to/file2.pdf /path/to/file1.txt`
