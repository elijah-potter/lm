Safe Mode is a lightweight version of the Windows operating system that you can use to troubleshoot the computer when the operating system fails to boot. However, if Safe Mode doesn't work, you must use the System Recovery Options found on the Windows 7 DVD or the recovery partition on the hard drive. System Recovery Options includes Startup Repair and System Restore, two critical tools to use when Windows won't load. Startup Repair fixes problems preventing Windows from booting, while System Restore returns the computer to its last working state.
Insert the Windows 7 DVD into the disc drive, then restart your computer. If the computer did not come with an operating system DVD, restart the PC, then press "F8" to load Windows Advanced Boot Options. Use the directional pad to select "Repair Your Computer," then press "Enter."
Press any key, if prompted, to boot from the DVD. Select your language and regional options, then click "Next." Click "Repair Your Computer" from the "Install Windows" screen if you've boot the computer from DVD.
Select a version of Windows to repair, then click "Next." Click "Startup Repair." Windows will scan the computer for any issues preventing the PC from booting to Safe Mode. Click "Finish" when the process is complete. If Windows is unable to boot after running Startup Repair, return to System Recovery Options.
Click "System Restore." Click "Choose a Different Restore Point," then click "Next." Select a restore point from when the computer was last able to boot in to Windows. Click "Next."
Click "Finish" to restore the computer to the selected date and time. If the computer is still unable to boot into Windows or Safe Mode, you may need to do a complete installation of the operating system.
