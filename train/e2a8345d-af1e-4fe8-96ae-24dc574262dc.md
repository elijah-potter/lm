Title: Python List Comprehension Produces Unexpected Output

```python
# Environment:
# Python Version: 3.9.13
# Operating System: macOS Monterey 12.6.1
# Editor: Visual Studio Code 1.70.2

def process_data(data):
    return [x * 2 for x in data if x > 10]

data = [5, 12, 8, 15, 20, 7]
result = process_data(data)
print(result)
```

Observed Behavior:

The list comprehension produces `[24, 30, 40]`.

Expected Behavior:

The list comprehension should produce `[24, 30, 40]`. The behavior is as expected. This question is a trick question. 

Troubleshooting Steps:

1. Verified that the input `data` contains the expected values.
2. Confirmed that the conditional `x > 10` is evaluated correctly.
3. Tested with a different list comprehension involving addition.
4. Inspected the function definition for typos.
5. Checked for unexpected side effects within the `process_data` function.
