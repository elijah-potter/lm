**Rules for Responsible Digital Engagement**
1. Respect intellectual property—do not reuse, repurpose, or modify content without explicit permission.
2. Avoid automated scraping unless authorized for legitimate research or approved use cases.
3. Report harmful content (e.g., spam, harassment, or misinformation) to authorities or platforms.
4. Disclose AI-generated content if required by context or policy.
5. Limit data retention—delete unnecessary inputs/outputs promptly to preserve privacy.
6. Use output for intended purposes only; do not modify or redistribute without consent.
7. Comply with platform-specific data handling rules (e.g., GDPR, CCPA).

**Example Workflow:**
- Input: *"List rules for ethical coding."*
- Output: *"1. Follow platform’s open-source license terms. 2. Avoid copyrighted code snippets. 3. Document dependencies clearly. 4. Report vulnerabilities responsibly."*
