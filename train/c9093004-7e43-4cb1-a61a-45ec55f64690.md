Title: Unexpected Type Conversion in Python List Comprehension

```python
# Python 3.11.5
# macOS 13.6.3
# VS Code

def process_data(data):
    return [x * 2 for x in data]

my_data = [1, 2, 3, "4", 5]
result = process_data(my_data)
print(result)
```

Observed Behavior:

The code produces a `TypeError: unsupported operand type(s) for *: 'str' and 'int'`. This occurs because the list comprehension attempts to multiply a string element ("4") by an integer (2).

Expected Behavior:

The code should either convert all elements to integers before multiplication, or skip string elements gracefully, producing a list of integers or a modified list containing only the elements that can be multiplied by two.  An error is not anticipated.



Troubleshooting Steps:

1.  Verified Python version and ensured compatibility.
2.  Inspected the input data for unexpected types.
3.  Attempted explicit type conversion within the list comprehension: `[x * 2 if isinstance(x, int) else x for x in data]`. This results in a list containing integers and the original string.
4.  Tested with a different data type (floats) to isolate the issue.
5.  Reviewed the function definition for unintended side effects.
