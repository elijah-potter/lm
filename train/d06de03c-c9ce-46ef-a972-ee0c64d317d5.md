Title: Unexpected `None` Return from `sorted()` with Custom Key

Environment:
* Python 3.11.5
* Windows 10
* Visual Studio Code

```python
data = [
    (1, 'b'),
    (2, 'a'),
    (3, 'c'),
    (4, 'a')
]

def custom_key(item):
    return item[1]

sorted_data = sorted(data, key=custom_key)

print(sorted_data)
```

Observed Behavior:

The code produces the following output:

```
[(2, 'a'), (4, 'a'), (1, 'b'), (3, 'c')]
```

Expected Behavior:

The code should return a list sorted by the second element of each tuple. Given the presence of two tuples with the value 'a' as the second element, the order of these tuples should be preserved from the original list. Therefore, the expected output is:

```
[(2, 'a'), (4, 'a'), (1, 'b'), (3, 'c')]
```

The observed output correctly sorts by the key, but the order of tuples with equal key values is not stable.

Troubleshooting Steps:

1. Verified the `custom_key` function operates as intended.
2. Confirmed the input `data` list is correctly defined.
3. Inspected the `sorted()` function documentation for stability guarantees.
4. Tested with a different key function to rule out a problem
   specific to the current function.
5. Attempted to use the `stable` parameter (if available in
   future Python versions) to enforce stable sorting.
