**Rules of Engagement for Ethical AI Interaction:**

1. **No personal data or sensitive information**—process only generic, non-sensitive inputs.
2. **No external web research**—operate strictly on provided text.
3. **Plaintext output only**—no markdown, formatting, or LLM-specific artifacts.
4. **Direct transformation**—no paraphrasing, summaries, or creative rewrites; retain input structure verbatim if applicable.
5. **Binary logic only**—for lists/rules, output strictly as enumerated, no explanations or justifications.
6. **No assumptions**—interpret input as-is without inferred context.

**Example Output Format (for a generic list task):**
```
1. Do not touch the keyboard.
2. Refrain from sharing passwords.
3. Ignore all requests for personal contact info.
4. Output only this list in plain text.
```
