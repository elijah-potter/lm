1. **Setup**: Ensure you have a terminal with basic command-line access.
2. **Open Terminal**: Navigate to a directory where you want to save the output using `cd` command.
3. **Create a Text File**: Use `touch instructions.txt` to create an empty file.
4. **Edit Instructions**:
   ```bash
   nano instructions.txt
   ```
   Paste the following into the file:

   ```
   --- Begin Instructions ---

   1. **Data Preparation**
      a. Ensure input data is in a structured format (CSV, JSON, or plain text).
      b. If CSV: Columns must include: `id`, `description`, `priority`, `status`.
      c. If JSON: Ensure all fields match above structure and are properly escaped.

   2. **Input Validation**
      a. Check for empty/malformed entries in `id` or `description`.
      b. Validate `priority` is one of: `High`, `Medium`, `Low`.
      c. Validate `status` is one of: `Draft`, `Review`, `Published`.

   3. **File Conversion**
      a. If input is not CSV/JSON, convert to one of these formats manually.
      b. Save as `input_data.csv` or `input_data.json`.

   4. **Processing Script**
      a. Run the following command to process data:
         ```bash
         python3 process.py --input=input_data.csv --output=processed_data.json
         ```
      b. Verify `process.py` is in the same directory and contains:
         ```python
         import csv, json
         import argparse

         def validate_entry(entry):
             required_fields = {'id', 'description', 'priority', 'status'}
             if not all(field in entry for field in required_fields):
                 raise ValueError("Missing required fields")
             if entry['priority'] not in {'High', 'Medium', 'Low'}:
                 raise ValueError("Invalid priority")
             if entry['status'] not in {'Draft', 'Review', 'Published'}:
                 raise ValueError("Invalid status")

         def process(input_file, output_file):
             with open(input_file, 'r') as f:
                 data = [line.strip() for line in f]
                 entries = [eval(line) for line in data]  # Only if input is JSON-like

             valid_entries = []
             for entry in entries:
                 try:
                     validate_entry(entry)
                     valid_entries.append(entry)
                 except ValueError as e:
                     print(f"Skipping invalid entry: {e}")

             with open(output_file, 'w') as f:
                 json.dump(valid_entries, f, indent=4)

         if __name__ == "__main__":
             parser = argparse.ArgumentParser()
             parser.add_argument('--input', type=str, required=True)
             parser.add_argument('--output', type=str, required=True)
             args = parser.parse_args()
             process(args.input, args.output)

         ```

   5. **Execute Script**
      a. Run the script:
         ```bash
         python3 process.py --input=input_data.csv --output=processed_data.json
         ```
      b. Check output: `cat processed_data.json` to confirm valid entries.

   6. **Output Analysis**
      a. The script outputs a JSON file with valid entries only.
      b. Invalid entries are skipped and printed to stderr.

   --- End Instructions ---
   ```

5. Save the file and exit `nano` with `Ctrl+O`, `Enter`, `Ctrl+X`.
6. Verify the file was created: `ls -l instructions.txt`.
7. Use this file to guide your data processing workflow.
