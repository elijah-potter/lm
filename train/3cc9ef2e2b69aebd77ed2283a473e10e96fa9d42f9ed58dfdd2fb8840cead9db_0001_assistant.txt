The `sklearn` Scikit-Learn library is required for that. Here is the code:

# Import the modules
from sklearn.ensemble import RandomForestClassifier
from sklearn import datasets
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, confusion_matrix, precision_score, recall_score

# Load the data
prices = datasets.load_prices()

# Define X and y
X, y = datasets.load_prices( return_X_y = True)

# Set training and testing values
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size = 0.30)

# Create a random forest classifier
prices_clf = RandomForestClassifier(n_estimators = 100)  

# Train the model
prices_clf.fit(X_train, y_train)

# Predict the values
y_predict = prices_clf.predict(X_test)

# Print the values
print("Accuracy: ", accuracy_score(y_test, y_predict))
print("Precision: ", precision_score(y_test, y_predict))
print("Recall: ", recall_score(y_test, y_predict))
print("Confusion Matrix: ", confusion_matrix(y_test, y_predict))

This imports `RandomForestClassifier`, `datasets`, train_test_split`, `accuracy_score`, `confusion_matrix`, `precision_score`, and `recall_score` from the `sklearn` library, allowing the code to ony load the necessary parts of the library instead of requiring it to handle the entire module at once. It loads your "prices" dataset and uses it to set the values of `X` and `y`. It trains the X and y testing and training sets with `train_test_split()`, then creats a random forest classifier `prices_clf` with `RandomForestClassifier()`. The data is fit to the classifier with `.fit()`, then the y values are predicted and passed to the accuracy, precision, recall, and confusion matrix methods as the parameters with the test data.
