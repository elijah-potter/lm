The return type of the zip function is an iterable whose first and only type parameter is a mapped type over T. The type parameter is an object containing all keys of T, and for each key, the corresponding value is determined by whether the value of the key in T is an iterable. If it is an iterable, the value in the mapped type is the extracted type of each element of the iterable. If it is not an iterable, the value in the mapped type is the value of the key in T.
