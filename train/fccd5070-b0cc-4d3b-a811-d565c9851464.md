Title: Unexpected Type Conversion in Python List Comprehension

Environment:
Python 3.9.13
macOS 12.6
Visual Studio Code

```python
numbers = [1, 2, 3, 1, 2, 3]
result = [str(x*2) for x in numbers if x % 2 == 0]
print(result)
```

Observed Behavior:

The code produces the output `['2', '4', '2', '4']`.  The list comprehension appears to be including duplicate entries.

Expected Behavior:

The code should produce the output `['2', '4']`.  The list comprehension should only include unique, even numbers multiplied by two, converted to strings.  The presence of the repeated '2' and '4' is unexpected.

Failed Troubleshooting Steps:

1. Verified the input list `numbers` contains no duplicates.
2. Confirmed the modulo operator (`%`) functions as expected.
3. Examined the conditional expression within the list comprehension.
4. Checked for unintended side effects from external libraries.
5. Simplified the list comprehension to isolate the issue.
