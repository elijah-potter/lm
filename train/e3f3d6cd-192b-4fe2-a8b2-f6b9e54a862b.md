1. **Setup:**
   - Ensure your terminal environment has Python 3.x installed.
   - Open a terminal and navigate to a directory where you want to save the script.

2. **Create Script File:**
   - Run the following command to create a new Python file:
     ```
     touch script.py
     ```

3. **Edit Script:**
   - Open `script.py` in a text editor:
     ```
     nano script.py
     ```

4. **Add Instructions:**
   Paste the following instructions into the script:

   ```python
   # Instructions for a Task Automation Script

   # --- Step 1: Import Required Libraries ---
   import os
   import shutil

   # --- Step 2: Define Paths ---
   source_dir = "/path/to/source/folder"  # Replace with your source directory
   destination_dir = "/path/to/destination/folder"  # Replace with your destination

   # --- Step 3: Check Directories ---
   if not os.path.exists(source_dir):
       print("Error: Source directory does not exist.")
       exit(1)
   if not os.path.exists(os.path.dirname(destination_dir)):
       os.makedirs(os.path.dirname(destination_dir))

   # --- Step 4: Copy Files ---
   files_to_copy = ["file1.txt", "file2.csv"]  # Add files to copy

   for file in files_to_copy:
       src_path = os.path.join(source_dir, file)
       dst_path = os.path.join(destination_dir, file)
       if os.path.isfile(src_path):
           shutil.copy2(src_path, dst_path)
           print(f"Copied {file} to {destination_dir}")
       else:
           print(f"Error: File {file} not found in source directory.")

   # --- Step 5: Execute ---
   ```

5. **Save and Exit:**
   - Press `Ctrl + O` to save, then `Enter`.
   - Press `Ctrl + X` to exit.

6. **Run the Script:**
   - Execute the script with:
     ```
     python script.py
     ```

7. **Customize:**
   - Update `source_dir`, `destination_dir`, and `files_to_copy` with your specific paths and files.
   - Adjust logic in the script as needed for your use case.

8. **Verify:**
   - Check destination directory to confirm files are copied correctly.
