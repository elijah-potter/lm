Sure! Loops are useful for when a set of instructions need to be repeated. Consider the following script:

```
p = 0
Loop, 5
    {
    p++
    Msgbox, % p
    }
```

This script starts with `p` equal to zero, but finishes with `p` equal to 5. The command `Loop, 5` means the code in the curly braces will be repeated 5 times sequentially and then the script will continue.

In the curly braces, `p++` means add one to `p`. The `Msgbox, % p` command displays the value on each loop.
