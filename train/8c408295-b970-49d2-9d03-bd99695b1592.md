1. **Convolutional Neural Networks (CNNs)** vs **Recurrent Neural Networks (RNNs)**:
   - **CNNs** excel in **spatial data** (e.g., images), using filters (kernels) to detect local patterns through hierarchical feature extraction.
   - **RNNs** are designed for **sequential data** (e.g., time series, text), maintaining state via recurrent connections to capture temporal dependencies.

2. **JSON** vs **YAML**:
   - **JSON** (JavaScript Object Notation) uses **key-value pairs with double quotes**, supports only strings, numbers, booleans, arrays, and objects; simpler parsing but less human-readable.
   - **YAML** (YAML Ain’t Markup Language) employs **indentation-based structure**, supports mixed types (e.g., strings, numbers, booleans, lists, dictionaries), and is more readable but requires careful parsing.

3. **Hardware vs Software**:
   - **Hardware** refers to **physical components** (e.g., CPU, RAM, GPU) that execute tasks via electrical signals.
   - **Software** is **programs/instructions** that manipulate hardware to achieve specific functions, abstracting hardware complexity.

4. **SQL vs NoSQL**:
   - **SQL (Structured Query Language)** uses **relational models** (tables, rows, columns) with rigid schema constraints for complex queries.
   - **NoSQL** databases (e.g., MongoDB) support **unstructured/unfixed schemas**, distributed storage, and horizontal scaling for scalability.

5. **Batch Processing vs Stream Processing**:
   - **Batch Processing** handles **large datasets in discrete chunks** (e.g., nightly ETL jobs) with offline computation.
   - **Stream Processing** processes **real-time/continuous data** (e.g., Kafka, Flink) with low-latency event-driven workflows.
