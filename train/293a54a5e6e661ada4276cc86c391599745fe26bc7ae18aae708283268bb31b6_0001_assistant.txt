Python has a separate `array` module that you can use specifically for arrays if you do not want to use NumPy. The module has a `.array()` method to create an array using the desired data type and a list of values as parameters in the format `.array(data_type, [list, of, values])`. Here is an example of it being used:

# Import the array module
import array

# Create an array
# Use "i" for an integer array or "d" for a double (float) array
array_1 = array.array("i", [1, 2, 3, 4])

# Display the array
print(array_1)
