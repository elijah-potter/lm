Introduction to PHP
This document is a brief introduction to PHP, one of the most useful features of people.emich.edu.
According to php.net, "PHP is a widely-used general-purpose scripting language that is especially suited for Web development and can be embedded into HTML." Simply put, it is software that runs on the web server, and allows you to embed code into your web pages to make them more dynamic.
PHP stands for "PHP Hypertext Preprocessor".
While PHP can be used to construct elaborate web applications, even non-programmers can utilize PHP to enhance their web pages. This document is written with casual web masters in mind, and only scratches the surface of PHP's capabilities.
