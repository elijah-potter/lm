That's a good question! To create your own module to use in Python, you first need to write a script that has the functions you want to use. You save those functions as `module_name.py`, replacing "module_name" with the name you want the module to have when you import it. The `.py` extension saves it as a Python file, which allows you to import the module as you would any other module you have installed. Then you can use the functions you created without including them directly in your script. For example:

# Create a function
def new_function(world):
    print(f"Hello, {world}.")

You create the function `new_function(world)` in Python and save it as `hello.py`. Then you open a new Python script and enter the following, using the module name and the new function:

# Import hello.py
import hello

# Use the function you created
hello.new_function("Maker")

This will give you the output, "Hello, Maker." You can use modules for functions, dictionaries, or any object that you will reuse in multiple scripts to keep your code more concise.
