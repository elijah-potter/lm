The AuthenticationManager returns an instance of the class that contains an authentication message. This message is sent to the Internet server to indicate that the client (such as WebRequest or one of its descendants) is authorized to access the server.
The instance is created by the authentication module that the AuthenticationManager designates to handle the request.
