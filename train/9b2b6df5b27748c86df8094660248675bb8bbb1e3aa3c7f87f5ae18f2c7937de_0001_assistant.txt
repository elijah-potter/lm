Of course, as requested an example using AutoHotkey v2.0.2 function that draws a triangle using MouseClickDrag:

```ahk
TriangleDraw() {
    CoordMode "Mouse", "Window" 
    MouseGetPos &currentX, &currentY

    MouseClickDrag "L", currentX, currentY, nextx := currentX, nexty := currentY - 100 
    MouseClickDrag "L", nextX, nexty, second_next_x := nextx + 100, Second_next_y := nexty 
    MouseClickDrag "L", second_next_x, Second_next_y, currentX, currentY 
}
```
The function starts by getting the current coordinate mode using CoordMode. The current mouse position is then stored in currentX and currentY. using the MouseGetPos function. The first side of the triangle is drawn using MouseClickDrag by dragging the left mouse button from the current position to the next position minus 100. The next side of the triangle is drawn the same way but adding 100 instead. The last line is drawn to finalize the triangle.
